## 摘要

本文讨论 Sendov 猜想及其由 Phelps–Rodriguez 提出的加强版本。最近，Lech Mazur 使用 AI 工具对所有 $n \geq 2$ 解决了 Sendov 猜想，证明在 Lean 中得到验证。陶哲轩对 AI 生成的证明进行了"人类消化"（human digestion），将其整理成可发表的预印本形式，并简化和优化了论证。本文完整呈现了消化后的证明，同时给出了 Rubinstein 定理的新证明。

## 一、猜想陈述

### 猜想 1（Sendov 猜想）

设 $n \geq 2$，$p: \mathbb{C} \to \mathbb{C}$ 是一个所有零点都在单位圆盘内的 $n$ 次多项式。则对于 $p$ 的每一个零点 $a$，存在 $p$ 的一个临界点 $\zeta$，使得

$$|\zeta - a| \leq 1.$$

### 猜想 2（Phelps–Rodriguez 猜想，加强版）

设 $n \geq 2$，$p: \mathbb{C} \to \mathbb{C}$ 是一个所有零点都在单位圆盘内的 $n$ 次多项式。则对于 $p$ 的每一个零点 $a$，存在 $p$ 的一个临界点 $\zeta$，使得

$$|\zeta - a| < 1,$$

除非 $a$ 在单位圆上且 $p$ 是 $z^n - a^n$ 的标量倍数。

通过绕原点旋转，可将 $a$ 规范化为满足 $0 \leq a \leq 1$ 的实数。Rubinstein 的工作已确立 $a = 1$ 的情形，因此只需考虑 $0 \leq a < 1$。两个猜想均可由以下猜想推出：

### 猜想 3（内部 Sendov 猜想）

设 $n \geq 2$，$p: \mathbb{C} \to \mathbb{C}$ 是一个所有零点都在单位圆盘内的 $n$ 次多项式。若 $0 \leq a < 1$ 是 $p$ 的零点，则存在 $p$ 的一个临界点 $\zeta$，使得

$$|\zeta - a| < 1.$$

## 二、历史背景

| 阶段 | 结果 |
|------|------|
| 低次情形 | $n \leq 8$ 已被证明（Brown 和 Xiang 等） |
| 高次情形 | 充分大的 $n$ 已被陶哲轩本人证明 |
| 中间情形 | 长期悬而未决 |
| 2026年 | Lech Mazur 使用 AI 工具对所有 $n \geq 2$ 完成证明，并在 Lean 中验证 |

陶哲轩之前的论证使用了一些定性成分（最显著的是解析延拓），因此不容易量化论证有效的 $n$ 的阈值。

最近，Lech Mazur 能够使用 AI 工具对所有 $n \geq 2$ 解决 Sendov 猜想，证明在 Lean 中得到验证。然而，AI 生成的证明尚未经过人类消化，不具备可发表的预印本形式；陶哲轩花了数天时间（在大量 AI 协助下）进行这样的消化，将证明置于先前文献的适当语境中，并简化和优化论证以突出主要思想。

这次消化的一个结果是，论证实际上证明了猜想 3，从而在完全一般性下解决了 Sendov 猜想和 Phelps–Rodriguez 猜想。

证明最终非常初等。除了代数基本定理（和关于 Möbius 变换的非常基本的事实）外，不使用复分析；作为输入使用的最深刻的不等式是 Maclaurin 不等式（而且我们只需要该不等式的一个特殊情形，可由算术平均-调和平均不等式和归纳论证导出）。

使用 AI 代理，陶哲轩已将整个论证在 Lean 中形式化，并通过小幅修改扩展到所有 $n \geq 2$。这个形式化比原始形式化更精简（约 15,000 行代码，而原始证明约有 90,000 行）。

## 三、证明概述

我们现在证明猜想 3。$n \leq 4$ 的情形早已为人所知，但需要单独处理；文末提供了使用此处开发的工具的简短证明。

假设现在我们对某个 $n \geq 5$ 有一个反例，即可以找到一个 $n$ 次多项式 $p$，其零点为

$$a, z_1, \ldots, z_{n-1},$$

其中 $0 \leq a < 1$，$z_j$（$j = 1, \ldots, n-1$）在闭单位圆盘内，且所有临界点到 $a$ 的距离都至少为 1。

我们在这里以非渐近意义使用 $O()$ 记号，即 $X = O(Y)$ 表示 $|X| \leq CY$，其中 $C$ 是某个绝对常数（与 $n$ 无关）。我们还使用记号 $O_{\leq}(Y)$ 表示一个量在量级上以 $Y$ 为界。

为捕捉临界点距 $a$ 至少为 1 的事实，将临界点写为

$$a - \frac{1}{q_1}, \ldots, a - \frac{1}{q_{n-1}},$$

其中 $q_1, \ldots, q_{n-1}$ 为闭单位圆盘内的非零复数。

### 例 4

若 $p(z) = z^n - 1$ 且 $a = 1$，则 $z_1, \ldots, z_{n-1}$ 是非平凡的 $n$ 次单位根，而 $q_1, \ldots, q_{n-1}$ 全部等于 1。严格来说，这并不是猜想 3 的反例（因为 $a$ 不严格小于 1）；尽管如此，这是下面论证的一个重要的近似反例。

### 例 5

陶哲轩论文第 4 节研究了前一个例子的推广。这里取

$$p(z) = \left(z + \frac{c_2}{n}\right)^m P(z) - \left(a + \frac{c_2}{n}\right)^m P(a),$$

其中 $n$ 是趋于无穷的渐近参数，

$$P(z) = (z - \lambda_1) \ldots (z - \lambda_m)$$

是某个 $m = O(1)$ 的低次多项式，

$$a = 1 - \frac{c_1}{n},$$

且 $c_1, c_2 > 0$ 为常数。这个多项式在 $a$ 处有一个零点，在 $-c_2/n$ 处有 $n-m-1$ 个临界点，在 $\lambda_1, \ldots, \lambda_m$ 附近有 $m$ 个额外的临界点。

## 四、通信恒等式

我们现在在闭单位圆盘内有两组点：$z_1, \ldots, z_{n-1}$ 和 $q_1, \ldots, q_{n-1}$。它们通过多项式 $p$ 及其一阶导数 $p'$ 相互"通信"，两者都可以用任一组点（以及 $n$ 和 $a$）表示。

事实上，如果我们将 $p$ 规范化为首一多项式，则可以用零点将 $p$ 分解为

$$p(z) = (z - a) \prod_{j=1}^{n-1} (z - z_j), \tag{2}$$

从而求导得

$$p'(z) = \left(\prod_{j=1}^{n-1} (z - z_j)\right) \left(1 + (z - a) \sum_{j=1}^{n-1} \frac{1}{z - z_j}\right). \tag{3}$$

类似地，$p'$ 可以分解为

$$p'(z) = n \prod_{j=1}^{n-1} \left(z - a + \frac{1}{q_j}\right), \tag{4}$$

从而积分（并利用 $p(a) = 0$）得

$$p(z) = (z - a) \int_0^1 n \prod_{j=1}^{n-1} \left(t(z - a) + \frac{1}{q_j}\right) dt. \tag{5}$$

方便起见，我们立即排除简单情形 $a = 0$。在这种情况下，从 (3)、(4) 可以看出

$$p'(0) = \prod_{j=1}^{n-1} (-z_j) = n \prod_{j=1}^{n-1} \frac{1}{q_j},$$

这是荒谬的，因为第一个乘积的量级至多为 1，而第二个乘积的量级至少为 1。因此我们可以假设 $a > 0$。

通过在各种自然位置检查 $p$ 或 $p'$，我们可以获得许多将 $z_j$ 与 $q_j$ 联系起来的恒等式。我们在这里记录实际需要的那些：

### 引理 6（通信恒等式）

设 $F$ 表示函数

$$F(t) := \prod_{j=1}^{n-1} (1 - atq_j). \tag{6}$$

- **(i)（质心恒等式）** 我们有

$$\frac{1}{n}\left(a + \sum_{j=1}^{n-1} z_j\right) = \frac{1}{n-1} \sum_{j=1}^{n-1} \left(a - \frac{1}{q_j}\right). \tag{7}$$

也就是说，零点的质心等于临界值的质心。

- **(ii)（极恒等式）** 我们有

$$\prod_{j=1}^{n-1} \frac{1 - az_j}{a - z_j} = \int_0^1 \prod_{j=1}^{n-1} \left(t(1 - a^2)q_j + a\right) dt. \tag{8}$$

- **(iii)（第一原点恒等式）** 我们有

$$(-1)^{n-1} \prod_{j=1}^{n-1} z_j = \frac{n a}{\prod_{j=1}^{n-1} q_j} \int_0^1 F(t) dt. \tag{9}$$

- **(iv)（第二原点恒等式）** 我们有

$$(-1)^{n-1} \prod_{j=1}^{n-1} z_j \left(1 + a \sum_{j=1}^{n-1} \frac{1}{z_j}\right) = \frac{n}{\prod_{j=1}^{n-1} q_j} F(1). \tag{10}$$

#### 证明

对于 (i)，我们检查 $p(z)$ 当 $z \to \infty$ 时的行为。从 (2) 我们有

$$p(z) = z^n - \left(a + \sum_{j=1}^{n-1} z_j\right) z^{n-1} + O(z^{n-2}),$$

从而逐项求导得

$$p'(z) = n z^{n-1} - (n-1)\left(a + \sum_{j=1}^{n-1} z_j\right) z^{n-2} + O(z^{n-3}).$$

同时，从 (4) 我们有

$$p'(z) = n z^{n-1} - n \left(\sum_{j=1}^{n-1} \left(a - \frac{1}{q_j}\right)\right) z^{n-2} + O(z^{n-3}).$$

比较系数，我们得到结论。

对于 (ii)，我们考虑表达式 $p(1/a)/p'(a)$。一方面，从 (2)、(3) 有

$$\frac{p(1/a)}{p'(a)} = \frac{(1/a - a) \prod_{j=1}^{n-1} (1/a - z_j)}{\prod_{j=1}^{n-1} (a - z_j)}.$$

另一方面，从 (4)、(5) 有

$$\frac{p(1/a)}{p'(a)} = \frac{(1/a - a) \int_0^1 n \prod_{j=1}^{n-1} \left(t \frac{1}{a} + \frac{1}{q_j}\right) dt}{n \prod_{j=1}^{n-1} \frac{1}{q_j}}.$$

将两个恒等式相等，经过一些代数运算得到 (ii)。

对于 (iii)，我们计算 $p(0)$。从 (2) 我们有

$$p(0) = -a(-1)^{n-1} \prod_{j=1}^{n-1} z_j,$$

而从 (5) 我们有

$$p(0) = -a \int_0^1 n \prod_{j=1}^{n-1} \left(-at + \frac{1}{q_j}\right) dt.$$

将两个恒等式相等，使用 (6) 经过一些代数运算得到 (iii)。

对于 (iv)，我们类似地计算 $p'(0)$。从 (3) 我们有

$$p'(0) = (-1)^{n-1} \left(\prod_{j=1}^{n-1} z_j\right) \left(1 + a \sum_{j=1}^{n-1} \frac{1}{z_j}\right),$$

而从 (4) 有

$$p'(0) = n \prod_{j=1}^{n-1} \left(-a + \frac{1}{q_j}\right).$$

将两个恒等式相等，使用 (6) 经过一些代数运算得到 (iv)。$\square$

值得注意的是，多项式 $p$ 在论证中不再起进一步作用：(i)–(iv) 中的恒等式，加上 $0 \leq a < 1$ 且 $z_j, q_j$ 位于闭单位圆盘内的假设，本身就足以获得矛盾。

## 五、关键参数定义

引入规范化量

$$\alpha := \frac{n-1}{2}(1 - a^2), \tag{11}$$

因此 $0 < \alpha < \frac{n-1}{2}$，而情形 $a = 1 - O(1/n)$ 对应于 $\alpha = O(1)$。非正式地说，$\alpha$ 衡量 $a$ 接近 1 的程度（在 $O(1/n)$ 的尺度上）。

论证中的一个关键角色是 $q_j$ 的均值

$$x + iy := \frac{1}{n-1} \sum_{j=1}^{n-1} q_j, \tag{12}$$

特别是实部 $x$。由于所有 $q_j$ 都在单位圆盘内，均值 $x+iy$ 也在单位圆盘内，因此

$$-1 \leq x \leq 1,$$

且

$$|y| \leq \sqrt{1 - x^2}. \tag{13}$$

方便起见，我们使用二次多项式

$$\beta(t) := 1 - 2axt + a^2 t^2 = 1 - x^2 + (x - at)^2, \tag{14}$$

特别关注在 $t=1$ 处的值：

$$\beta(1) = 1 - 2ax + a^2 = (1 - a)^2 + 2a(1 - x) = 1 - x^2 + (x - a)^2. \tag{15}$$

应该主要将 $\beta(1)$ 视为 $x$ 接近 1 的程度的度量。显然，对于所有 $0 \leq t \leq 1$，我们有 $\beta(t) > 0$（注意 $at$ 严格小于 1）。

## 六、极不等式

论证将围绕 $\alpha$ 与 $\beta(1)$ 之间的关系展开。具体来说，我们将建立以下两个不等式。第一个不等式，我们称之为"极不等式"，有三种形式：

### 命题 10（极不等式）

- **(i)（原始极不等式）** 我们有

$$1 \leq \int_0^1 \left(a^2 + 2atx(1 - a^2) + t^2(1 - a^2)^2\right)^{\frac{n-1}{2}} dt. \tag{16}$$

- **(ii)（$\alpha, \beta(1)$ 形式的极不等式）** 我们有

$$1 < \int_0^1 \exp(\alpha(-1 + (2 - \beta(1))t)) dt. \tag{17}$$

- **(iii)（简化极不等式）** 我们有

$$0 < \beta(1) < \min\left(\frac{\alpha}{3 + \alpha}, 1 - \frac{\log \alpha}{\alpha}\right). \tag{18}$$

特别地，由于 $1 - \beta(1) = 2a(x - a/2)$，我们有

$$x > a/2 > 0.$$

实际上我们使用的是不等式 (18)，但它由 (17) 导出，而 (17) 又是 (16) 的推论，(16) 则由极恒等式 (8) 以及 $z_j$ 和 $q_j$ 位于单位圆盘内的事实得出。

### 6.1 极不等式的证明

众所周知，Möbius 变换 $z \mapsto \frac{d - az}{1 - az}$ 将闭单位圆盘映射到自身。特别地，对于所有零点 $z_j$，我们有

$$\left|\frac{1 - az_j}{a - z_j}\right| \geq 1.$$

将其代入极恒等式 (8) 并使用三角不等式，我们得到下界

$$1 \leq \int_0^1 \prod_{j=1}^{n-1} |t(1 - a^2)q_j + a| dt. \tag{23}$$

现在我们将这个界转换为涉及 (12) 中量 $x$ 的界。由算术平均-几何平均不等式，我们有

$$\prod_{j=1}^{n-1} |t(1 - a^2)q_j + a| \leq \left(\frac{1}{n-1} \sum_{j=1}^{n-1} |t(1 - a^2)q_j + a|^2\right)^{\frac{n-1}{2}}, \tag{24}$$

而由 (12) 我们有

$$\sum_{j=1}^{n-1} |t(1 - a^2)q_j + a|^2 = (n-1)(a^2 + t^2(1 - a^2)^2) + 2at(1 - a^2)(n-1)x.$$

由于 $|y|^2 \leq 1 - x^2$，因此我们有

$$\frac{1}{n-1} \sum_{j=1}^{n-1} |t(1 - a^2)q_j + a|^2 \leq a^2 + 2atx(1 - a^2) + t^2(1 - a^2)^2, \tag{25}$$

给出原始极不等式 (16)。

用 $t$ 界 $t^2$ 并使用 (11)、(15) 中的量 $\alpha, \beta(1)$，我们观察到

$$a^2 + 2atx(1 - a^2) + t^2(1 - a^2)^2 \leq 1 + \frac{2}{n-1} \alpha(-1 + (2 - \beta(1))t).$$

使用基本不等式 $1 + y \leq \exp(y)$，我们因此有

$$\left(a^2 + 2atx(1 - a^2) + t^2(1 - a^2)^2\right)^{\frac{n-1}{2}} \leq \exp(\alpha(-1 + (2 - \beta(1))t)),$$

对于 $t < 1$ 严格不等。从 (16) 我们得出 (17)。

计算 (17) 中的积分，我们得到

$$1 < \frac{e^{\alpha(1 - \beta(1))} - e^{-\alpha}}{\alpha(2 - \beta(1))},$$

从而

$$e^{\alpha(1 - \beta(1))} > \alpha(2 - \beta(1)) + e^{-\alpha} \geq \alpha,$$

所以取对数我们得到

$$1 - \beta(1) > \frac{\log \alpha}{\alpha}.$$

还需要建立界

$$\beta(1) < \frac{\alpha}{3 + \alpha}. \tag{26}$$

这里使用一个 AI 生成的论证。可以直接计算

$$\int_0^1 \exp(\alpha(-1 + (2 - \beta(1))t)) dt = e^{-\alpha} \frac{\sinh h}{h},$$

其中 $u = \alpha \beta(1)/2$，$h = \alpha(2 - \beta(1))/2$。如果我们能证明

$$\log \frac{\sinh h}{h} \leq \sqrt{h^2 + 9} - 3 \tag{27}$$

对所有 $h > 0$ 成立，那么在 (17) 中取对数得到

$$u < \log \frac{\sinh h}{h} \leq \sqrt{h^2 + 9} - 3,$$

由此通过常规代数运算可推出 (26)。

(27) 的两边在 $h=0$ 处都为零。求导，只需证明

$$\coth h - \frac{1}{h} \leq \frac{h}{\sqrt{h^2 + 9}},$$

这重新排列为

$$h^4 \sinh^2 h - (h^2 + 9)(h \cosh h - \sinh h)^2 \geq 0.$$

使用双角公式展开左边，可以证明它具有 Taylor 展开

$$\sum_{k=3}^{\infty} \frac{2^{2k-3}(k-1)(2k-6)^2}{(2k)!} h^{2k},$$

其中每个系数都是非负的，从而给出结论。

## 七、原点不等式

第二个不等式更困难，也有几种形式：

### 命题 11（原点不等式）

设 $n \geq 5$。

- **(i)（原始原点不等式）** 我们有

$$2\alpha + ax \leq \frac{1 - x^2}{2n(n-1)} + a^2 n(n-1) \int_0^1 t \beta(t)^{\frac{n-2}{2}} dt. \tag{19}$$

- **(ii)（$\alpha$ 界）** 我们有

$$\alpha \leq 17. \tag{20}$$

- **(iii)（$\alpha, \beta(1)$ 形式的原点不等式）** 我们有

$$1 \leq \frac{\beta(1)}{2\alpha} + \frac{\beta(1)}{a(\alpha+1)} + \frac{1}{2\alpha-1} + \frac{4(n-1)}{a^4(n-2)^3}. \tag{21}$$

(i) 部分（从原始 AI 生成论证的第 6 节中费力提取）将由第一和第二原点恒等式 (9)、(10) 以及质心恒等式 (7) 推出。(ii) 部分由 (i) 和极不等式 (18) 推出，而 (iii) 是 (i) 的初等推论。

事实证明，(21) 中的最后三项在 $n \to \infty$ 时渐近可忽略。去掉这些项给出了一个与极不等式 (17)（或 (18)）不相交的 $\alpha$ 和 $\beta(1)$ 的竞争可行区域。

这已经表明可以使用这种方法恢复陶哲轩先前关于 Sendov 猜想对所有充分大的 $n$ 成立的结果。事实上，即使加上 (21) 中的三个误差项，不等式 (18) 和 (21) 之间也有足够的空间来对所有 $n \geq 5$ 获得矛盾（使用额外的界 $\alpha \leq 17$ 来控制这些误差），尽管对中等大小的 $n$（例如 $5 \leq n \leq 200$）证明这一点需要一定量的计算机辅助。

## 八、Rubinstein 定理

我们现在调整论证来给出 Rubinstein 定理的证明，即 Phelps–Rodriguez 猜想在 $a=1$ 的情形成立：

### 定理 14（Rubinstein 定理）

设 $n \geq 2$，$p: \mathbb{C} \to \mathbb{C}$ 是一个所有零点都在单位圆盘内的 $n$ 次多项式。若 $p(1) = 0$，则存在 $p$ 的一个临界点 $\zeta$，使得

$$|\zeta - 1| < 1,$$

除非 $p$ 是 $z^n - 1$ 的标量倍数。

这里的论证本质上在 Tang 和 Zhang 论文的注记 5.1 中。

取逆否命题，我们可以假设临界点 $\zeta_j$ 形如 $1 - 1/q_j$，其中 $q_j$ 在闭单位圆盘内，并将 $p$ 规范化为首一多项式；我们的任务是证明 $p(z) = z^n - 1$。

基于计算 $p(1/a)/p'(a)$ 的极恒等式 (8) 在 $a=1$ 时退化为平凡式，但我们有以下可用的替代式，对任意选择的 $a$ 都有效，首先在 Meir–Sharma 的方程 (3.2) 中观察到：

### 引理 15（Meir–Sharma 恒等式）

若 $p(a) = 0$ 且临界点形如 $a - 1/q_j$，则所有零点 $z_j$ 都不等于 $a$，且

$$\sum_{j=1}^{n-1} q_j = 2 \sum_{j=1}^{n-1} \frac{1}{a - z_j}.$$

现在取 $a=1$。由于 $z_j$ 位于闭单位圆盘内，$\frac{1}{1-z_j}$ 的实部至少为 $1/2$，而 $\operatorname{Re} q_j$ 至多为 1。因此，上述恒等式成立的唯一方式是对所有 $j$ 有 $\operatorname{Re} q_j = 1$，从而对所有 $j$ 有 $q_j = 1$。因此所有临界点都在原点，这迫使 $p(z) = c(z^n - 1)$ 对某个 $c$ 成立。由于 $p(1) = 0$，我们得出 $c=1$，给出结论。

## 九、$n \leq 4$ 的情形

我们现在证明猜想 3 的 $n \leq 4$ 情形。起点是 (23)。使用三角不等式和 $|q_j| \leq 1$，这意味着

$$1 \leq \int_0^1 (a + (1 - a^2)t)^{n-1} dt.$$

由 Hölder 不等式和 $n \leq 4$，我们得出

$$1 \leq \int_0^1 (a + (1 - a^2)t)^3 dt.$$

右边可以计算为等于

$$1 - \frac{(a-1)^2}{4}(a^2(1-a)^2 + 3(1-a^2) + 2a),$$

对于 $0 \leq a < 1$，这显然小于 1，给出矛盾。

**注记 16：** 同样的论证对 $n=5$ 也有效，但对更高的 $n$ 失效。

## 十、进一步方向

Sendov 和 Phelps–Rodriguez 猜想现在已解决，但几个相关猜想仍然开放。

### 猜想 17（Borcea 猜想）

设 $1 \leq q < \infty$ 且 $n \geq 2$，$p$ 是一个 $n$ 次多项式，其零点 $z_1, \ldots, z_n$ 满足 $\frac{1}{n} \sum_{j=1}^n |z_j|^q \leq 1$。则对于 $p$ 的每一个零点 $a$，存在 $p$ 的一个临界点 $\zeta$，使得 $|\zeta - a| \leq 1$。

Sendov 猜想是这个猜想的极限情形 $q = \infty$。关于这个猜想的进展相对较少：情形 $(q,n) = (1,3), (2,4)$ 已由 Khavinson、Pereira、Putinar、Saff 和 Shimorin 确立。这里的证明方法似乎不容易推广；所有将零点和临界点联系起来的恒等式仍然成立，但现在 $z_j$ 只在平均矩意义下被约束在单位圆盘内，上面开发的所有不等式现在都失效了。

### 猜想 18（Schmeisser 猜想）

设 $n \geq 2$，$p$ 是一个所有零点都在闭单位圆盘内的 $n$ 次多项式。则对于 $p$ 零点凸包中的任意 $a$，存在 $p$ 的一个临界点 $\zeta$，使得 $|\zeta - a| \leq 1$。

### 猜想 19（Tang–Zhang 猜想）

设 $n \geq 2$，$p$ 是一个所有零点都在闭单位圆盘内且临界点为 $a - 1/q_j$ 的 $n$ 次多项式。则对于任意 $\lambda \geq 1$，有 $\sum_{j=1}^{n-1} |q_j|^\lambda \geq n - 1$。

Sendov 猜想是极限情形 $\lambda = \infty$。由 Hölder 不等式，$\lambda = 1$ 的情形是猜想的最强形式。

### 猜想 20（Smale 问题）

设 $n \geq 2$，$p$ 是一个 $n$ 次多项式。则对于 $p$ 的任意零点 $a$，存在 $p$ 的一个临界点 $\zeta$，使得

$$|p(\zeta)| \leq \left(1 - \frac{1}{n}\right) |\zeta - a| |p'(a)|.$$

常数 $1 - 1/n$ 是最佳可能的，如例子 $p(z) = z^n - z$ 和 $a=0$ 所示。使用 Koebe 四分之一定理，Smale 证明了这个猜想，其中 $1 - 1/n$ 被替换为 4。多年来获得了一些轻微的改进；例如对于 $n \geq 8$，Crane 获得了 $4 - \frac{2.05}{\sqrt{n}}$ 的改进界。

不用说，陶哲轩确实尝试了一些零散的尝试使用 AI 工具来攻击这些问题，但没有取得显著成功。

一个潜在的前进方向是找到利用其他技术的 Sendov 猜想的进一步证明，这些技术可能更广泛地适用于这更大的问题族。这里的证明值得注意的是，零点和临界点几乎被当作独立的数学对象对待，只通过四个恒等式非常狭窄地相互通信，其中人们只在少数几个点检查底层多项式（及其导数）。可能专注于多项式更多全局特征的方法可能会导致 Sendov 猜想的新证明，也许还有其推广。
