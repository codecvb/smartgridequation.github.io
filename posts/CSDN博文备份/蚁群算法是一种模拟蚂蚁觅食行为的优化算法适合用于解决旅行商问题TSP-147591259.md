<p>蚁群算法是一种模拟蚂蚁觅食行为的优化算法，适合用于解决旅行商问题（TSP）。以下是使用 MATLAB 实现蚁群算法解决 50 个城市 TSP 问题的代码：</p> <br><p style="text-align:center"><img alt="" 个城市的坐标，接着算出城市之间的距离矩阵。</li><li><strong>蚁群算法参数设置</strong>：对蚂蚁数量、迭代次数、信息素重要程度因子、启发式因子、信息素挥发因子以及信息素增加强度系数等参数进行设置。</li><li><strong>信息素矩阵初始化</strong>：把信息素矩阵初始化为全 1 矩阵。</li><li><strong>蚁群算法主循环</strong>： <br>  <ul><li>每只蚂蚁随机选择起始城市，再依据信息素和距离计算转移概率，采用轮盘赌的方式选择下一个城市，从而构建完整的路径。</li><li>计算每只蚂蚁路径的总距离，更新最优解。</li><li>按照信息素挥发和增加规则更新信息素矩阵。</li></ul> </li><li><strong>绘制最优路线</strong>：将最优路线首尾相连，然后绘制出城市和最优路线。</li></ol> 初始化信息素矩阵<br>pheromoneMatrix = ones(numCities, numCities);<br><br>% 初始化最优解<br>bestRoute = [];<br>bestDistance = Inf;<br><br>% 蚁群算法主循环<br>for iter = 1:numIterations<br>    % 初始化所有蚂蚁的路径<br>    allRoutes = zeros(numAnts, numCities);<br>    allDistances = zeros(numAnts, 1);<br>    <br>    % 每只蚂蚁构建路径<br>    for ant = 1:numAnts<br>        % 随机选择起始城市<br>        currentCity = randi(numCities);<br>        unvisitedCities = setdiff(1:numCities, currentCity);<br>        route = currentCity;<br>        <br>        % 依次选择下一个城市<br>        for i = 2:numCities<br>            % 计算转移概率<br>            probabilities = (pheromoneMatrix(currentCity, unvisitedCities).^alpha) .* ((1./distMatrix(currentCity, unvisitedCities)).^beta);<br>            probabilities = probabilities / sum(probabilities);<br>            <br>            % 轮盘赌选择下一个城市<br>            nextCityIndex = randsample(length(unvisitedCities), 1, true, probabilities);<br>            nextCity = unvisitedCities(nextCityIndex);<br>            <br>            % 更新路径和未访问城市集合<br>            route = [route nextCity];<br>            unvisitedCities = setdiff(unvisitedCities, nextCity);<br>            currentCity = nextCity;<br>        end<br>        <br>        % 记录当前蚂蚁的路径和总距离<br>        allRoutes(ant, :) = route;<br>        allDistances(ant) = calculateTotalDistance(route, distMatrix);<br>    end<br>    <br>    % 更新最优解<br>    [minDistance, minIndex] = min(allDistances);<br>    if minDistance < bestDistance<br>        bestDistance = minDistance;<br>        bestRoute = allRoutes(minIndex, :);<br>    end<br>    <br>    % 更新信息素矩阵<br>    pheromoneMatrix = (1 - rho) * pheromoneMatrix;<br>    for ant = 1:numAnts<br>        route = allRoutes(ant, :);<br>        for i = 1:numCities - 1<br>            pheromoneMatrix(route(i), route(i + 1)) = pheromoneMatrix(route(i), route(i + 1)) + Q / allDistances(ant);<br>            pheromoneMatrix(route(i + 1), route(i)) = pheromoneMatrix(route(i + 1), route(i)) + Q / allDistances(ant);<br>        end<br>        pheromoneMatrix(route(numCities), route(1)) = pheromoneMatrix(route(numCities), route(1)) + Q / allDistances(ant);<br>        pheromoneMatrix(route(1), route(numCities)) = pheromoneMatrix(route(1), route(numCities)) + Q / allDistances(ant);<br>    end<br>end<br><br>% 回到起始城市<br>bestRoute = [bestRoute bestRoute(1)];<br><br>% 绘制最优路线<br>figure;<br>hold on;<br>plot(cities(:, 1), cities(:, 2), 'ko', 'MarkerSize', 5, 'LineWidth', 1); % 绘制城市<br>for j = 1:numCities<br>    startCity = bestRoute(j);<br>    endCity = bestRoute(j + 1);<br>    plot([cities(startCity, 1) cities(endCity, 1)], [cities(startCity, 2) cities(endCity, 2)], 'b-', 'LineWidth', 0.5);<br>end<br>title(sprintf('最优路线总距离: %.2f', bestDistance));<br>xlabel('X
