<p>本文介绍了一个基于YOLO的目标检测类ObjectDetector，支持YOLOv8标准模型和YOLO-World自定义模型。该类提供了两种模型加载方式：标准YOLOv8模型（80类）和可自定义检测类别的YOLO-World模型。主要功能包括模型自动加载和单张图片检测，能够输出检测目标的类别、数量和平均置信度，并保存检测结果图像。使用示例展示了如何初始化检测器并进行图片检测。该实现具有自动回退机制，当指定模型加载失败时会自动切换为标准模型。</p><br><br><p><img alt="" height="2000" src="https://i-blog.csdnimg.cn/direct/e434b11466814458ab0aab0f45bfe52b.png" width="3200" /><img alt="" height="3640" src="https://i-blog.csdnimg.cn/direct/f76c0beee0e94aa5b245ef19eee2247a.jpeg" width="2048" /></p><br><br><pre><br><code class="language-python">from ultralytics import YOLO<br>import cv2<br>import os<br><br>class ObjectDetector:<br>    def __init__(self, model_type='standard'):<br>        """<br>        参数:<br>            model_type: 'standard' 或 'world'<br>        """<br>        self.model_type = model_type<br>        self.model = None<br>        self.load_model()<br>    <br>    def load_model(self):<br>        """加载模型"""<br>        try:<br>            if self.model_type == 'world':<br>                # 加载YOLO World模型<br>                self.model = YOLO("E:/PYTHON/object_regconnition/YOLO-World/yolo_world_v2_l_clip_large_o365v1_goldg_pretrain_800ft-9df82e55.pth")<br>                # 设置自定义类别<br>                custom_classes = ["person", "bicycle", "car", "motorcycle", "bus", "truck", <br>                                "dog", "cat", "bird", "chair", "table", "laptop", "phone"]<br>                self.model.set_classes(custom_classes)<br>                print("✅ YOLO World模型加载成功，使用自定义类别")<br>                <br>            else:<br>                # 加载标准YOLOv8模型<br>                self.model = YOLO('yolov8n.pt')<br>                print("✅ 标准YOLOv8模型加载成功，使用80个预定义类别")<br>                <br>            print(f"📊 可检测类别数量: {len(self.model.names)}")<br>            <br>        except Exception as e:<br>            print(f"❌ 模型加载失败: {e}")<br>            # 回退到标准模型<br>            print("🔄 回退到标准YOLOv8模型...")<br>            self.model = YOLO('yolov8n.pt')<br>            self.model_type = 'standard'<br>    <br>    def detect_image(self, image_path, save_result=True):<br>        """检测单张图片"""<br>        if not os.path.exists(image_path):<br>            print(f"❌ 图片不存在: {image_path}")<br>            return<br>        <br>        try:<br>            # 进行预测<br>            results = self.model.predict(image_path, conf=0.25)<br>            <br>            # 处理结果<br>            result = results[0]<br>            <br>            # 打印检测结果<br>            print(f"\n🎯 在 {os.path.basename(image_path)} 中检测到:")<br>            print("-" * 50)<br>            <br>            detections = {}<br>            for box in result.boxes:<br>                cls_id = int(box.cls.item())<br>                confidence = box.conf.item()<br>                class_name = self.model.names[cls_id]<br>                <br>                if class_name not in detections:<br>                    detections[class_name] = []<br>                detections[class_name].append(confidence)<br>            <br>            # 保存结果图像<br>            if save_result:<br>                output_path = f"detected_{os.path.basename(image_path)}"<br>                result.save(filename=output_path)<br>                print(f"💾 结果保存为: {output_path}")<br>            <br>            return result<br>            <br>        except Exception as e:<br>            print(f"❌ 检测失败: {e}")<br>            return None<br><br># 使用示例<br>if __name__ == "__main__":<br>    #
