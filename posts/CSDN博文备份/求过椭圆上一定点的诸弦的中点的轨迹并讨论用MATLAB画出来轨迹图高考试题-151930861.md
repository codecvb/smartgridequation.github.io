<p>本文通过MATLAB程序展示了椭圆中弦中点轨迹的性质。</p><br><br><p>给定一个长半轴2、短半轴1的椭圆，程序选取椭圆上的定点P(2,0)，生成过P点的8条弦并计算其中点，发现这些中点都落在中心在(1,0)、长半轴1、短半轴0.5的小椭圆上。</p><br><br><p>通过参数方程绘制原椭圆和轨迹椭圆，并可视化展示弦及其中点，验证了椭圆中弦中点轨迹仍为椭圆的几何性质。当P点在原椭圆上移动时，轨迹椭圆的中心也会随之移动。</p><br><br><p class="img-center"><img alt="" height="422" src="https://i-blog.csdnimg.cn/direct/81c630a740494e5e80ee8da7881a7d75.png" width="1015" /></p><br><br><p class="img-center"><img alt="" height="410" src="https://i-blog.csdnimg.cn/direct/47737f6b18af486388bcbb3938ea3efa.png" width="885" /></p><br><br><p class="img-center"><img alt="" height="446" src="https://i-blog.csdnimg.cn/direct/8c101a739fdd459aa7b0ad2c1613fe29.png" width="1207" /></p><br><br><p><img alt="" height="547" src="https://i-blog.csdnimg.cn/direct/e090373eff3a4970acef46d7d0da7b88.png" width="1223" /></p><br><br><pre><br><code class="language-Matlab">% 1. 定义参数（原椭圆与定点）<br>a = 2;          % 原椭圆长半轴<br>b = 1;          % 原椭圆短半轴<br>x0 = 2;         % 定点P的x坐标<br>y0 = 0;         % 定点P的y坐标<br><br>% 2. 生成原椭圆的点（参数方程）<br>theta = linspace(0, 2*pi, 1000);  % θ从0到2π，取1000个点<br>x_ellipse = a * cos(theta);<br>y_ellipse = b * sin(theta);<br><br>% 3. 生成轨迹小椭圆的点（参数方程）<br>h = x0 / 2;     % 轨迹椭圆中心x坐标<br>k = y0 / 2;     % 轨迹椭圆中心y坐标<br>a_prime = a / 2;% 轨迹椭圆长半轴<br>b_prime = b / 2;% 轨迹椭圆短半轴<br>x_trace = h + a_prime * cos(theta);<br>y_trace = k + b_prime * sin(theta);<br><br>% 4. 生成过定点P的若干条弦及其中点<br>num_chords = 8;  % 选取8条弦进行展示<br>theta_points = linspace(0, 2*pi, num_chords+1);  % 均匀分布的角度点<br>theta_points(end) = [];  % 去除最后一个点（与第一个重复）<br><br>% 存储弦的端点和中点<br>x1 = zeros(1, num_chords);<br>y1 = zeros(1, num_chords);<br>x2 = zeros(1, num_chords);<br>y2 = zeros(1, num_chords);<br>mid_x = zeros(1, num_chords);<br>mid_y = zeros(1, num_chords);<br><br>for i = 1:num_chords<br>    % 第一个端点：根据角度生成<br>    theta1 = theta_points(i);<br>    x1(i) = a * cos(theta1);<br>    y1(i) = b * sin(theta1);<br>    <br>    % 计算第二个端点（确保与P、第一个端点共线且在椭圆上）<br>    % 通过直线方程与椭圆方程联立求解<br>    if x1(i) ~= x0  % 避免垂直直线<br>        m = (y1(i) - y0) / (x1(i) - x0);
