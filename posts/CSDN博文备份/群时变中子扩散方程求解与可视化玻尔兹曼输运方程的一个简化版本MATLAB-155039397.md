<p>本文实现了一维两群中子扩散方程的数值求解与可视化。采用有限差分法离散空间变量，向后欧拉法处理时间变量，模拟了中子通量在20cm平板介质中的时变传播。快中子（群1）和热中子（群2）分别设置不同的扩散系数、吸收截面和散射截面，初始条件下在中心位置设置高斯脉冲源。程序实现了真空边界条件，并通过周期性地绘制通量分布来展示演化过程。最终输出两个中子群在模拟结束时刻的详细空间分布。该代码为玻尔兹曼输运方程提供了简化的一维两群扩散求解方案，可用于中子输运基本特性的教学研究。</p><br><br><p class="img-center"><img alt="" src="https://i-blog.csdnimg.cn/direct/d22b88acec374c81b8781cb9c9aaea22.jpeg" /></p><br><br><p class="img-center"><img alt="" src="https://i-blog.csdnimg.cn/direct/d95251616bc547529e9cee69fd8c8bf4.jpeg" /></p><br><br><pre><br><code class="language-Matlab">% ================================================================<br>% 1D, 2群时变中子扩散方程求解与可视化<br>% 这个代码是玻尔兹曼输运方程的一个简化版本<br>% ================================================================<br><br>clear; clc; close all;<br><br>%% 1. 定义物理参数和计算网格<br>L = 20.0;                 % 平板介质厚度 [cm]<br><br>% --- 群 1 (快中子) 参数 ---<br>D1 = 1.5;                 % 扩散系数 [cm]<br>Sigma_a1 = 0.01;          % 吸收截面 [1/cm]<br>Sigma_s12 = 0.1;          % 散射到群2的截面 [1/cm]<br>Sigma1 = Sigma_a1 + Sigma_s12; % 总去除截面<br><br>% --- 群 2 (热中子) 参数 ---<br>D2 = 0.5;                 % 扩散系数 [cm]<br>Sigma_a2 = 0.2;           % 吸收截面 [1/cm]<br>Sigma2 = Sigma_a2;<br><br>% --- 时间和空间离散化 ---<br>Nx = 40;                  % 空间网格节点数<br>x = linspace(0, L, Nx);   % 生成空间坐标网格<br>dx = x(2) - x(1);         % 计算网格步长<br><br>t_max = 5.0;              % 最大模拟时间 [s]<br>Nt = 100;                 % 时间步数<br>dt = t_max / Nt;          % 时间步长<br><br>%% 2. 初始化通量数组<br>Phi1 = zeros(Nx, 1);      % 群1通量<br>Phi2 = zeros(Nx, 1);      % 群2通量<br><br>% 设置初始条件 (例如，在中心有一个脉冲源)<br>source_width = 2.0;<br>source_amplitude = 100.0;<br>for i = 1:Nx<br>    if abs(x(i) - L/2) < source_width<br>        Phi1(i) = source_amplitude * exp(-((x(i)-L/2)/source_width)^2);<br>    end<br>end<br><br>%% 3. 定义有限差分系数 (用于空间项)<br>% 对于内部节点，Laplacian算子 ∇·D∇Φ 的离散形式为:<br>% D*(Phi(i+1) - 2*Phi(i) + Phi(i-1)) / dx^2<br>coeff = 1 / dx^2;<br><br>%% 4. 时间演化与求解<br>figure('Name', '1D, 2群中子通量时间演化');<br><br>for n = 1:Nt<br>    % 创建用于求解下一时间步的矩阵<br>    % 为了效率，我们使用原地更新，而不是每次都创建新矩阵<br>    <br>    % --- 更新群 1 ---<br>    Phi1_new = Phi1;<br>    for i = 2:Nx-1 % 内部节点<br>        % 向后欧拉法离散:<br>        % (Phi1_new - Phi1_old)/dt = D1*Laplacian(Phi1_new) - Sigma1*Phi1_new + S1<br>        % 整理得:<br>        % Phi1_new - dt*D1*Laplacian(Phi1_new) + dt*Sigma1*Phi1_new = Phi1_old + dt*S1<br>        <br>        % 此处 S1 = 0 (除了初始条件)<br>        lhs = 1.0 + dt * (D1 * coeff * 2.0 + Sigma1);<br>        rhs = Phi1(i) + dt * D1 * coeff * (Phi1(i+1) + Phi1(i-1));<br>        <br>        Phi1_new(i) = rhs / lhs;<br>    end<br>    % 真空边界条件 (Neumann-like)<br>    Phi1_new(1) = Phi1_new(2);<br>    Phi1_new(end) = Phi1_new(end-1);<br>    <br>    % --- 更新群 2 ---<br>    Phi2_new = Phi2;<br>    for i = 2:Nx-1 % 内部节点<br>        % 向后欧拉法离散:<br>        % (Phi2_new -
