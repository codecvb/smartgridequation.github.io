<p>以下是用 C 语言实现的回调函数案例，涵盖基础用法及不同消息机制（GUI 模拟、网络请求模拟、状态机、消息队列），包含详细注释和解释。</p><br><br><h4>一、回调函数基础用法（计算器示例）</h4><br><br><p><strong>核心思想</strong>：将运算函数作为参数传递给主函数，实现逻辑解耦。</p><br><br><p>c</p><br><br><pre><br><code class="language-cpp">#include <stdio.h><br><br>// 回调函数类型定义：规定回调函数的参数和返回值<br>typedef int (*CalculateCallback)(int, int);<br><br>// 回调函数1：加法<br>int add(int a, int b) {<br>    return a + b;<br>}<br><br>// 回调函数2：减法<br>int subtract(int a, int b) {<br>    return a - b;<br>}<br><br>// 主函数：接收回调函数并执行<br>int calculate(int a, int b, CalculateCallback callback) {<br>    // 调用回调函数处理数据<br>    return callback(a, b);<br>}<br><br>int main() {<br>    // 传递不同的回调函数，实现不同运算<br>    printf("5 + 3 = %d\n", calculate(5, 3, add));       // 输出：8<br>    printf("5 - 3 = %d\n", calculate(5, 3, subtract));  // 输出：2<br>    return 0;<br>}<br></code></pre><br><br><p><strong>解释</strong>：</p><br><br><ul><li><code>typedef int (*CalculateCallback)(int, int)</code> 定义了回调函数类型，约束回调函数必须接收两个<code>int</code>参数并返回<code>int</code>。</li><li><code>calculate</code>函数通过参数接收回调函数，实现了 “调用逻辑” 与 “具体运算逻辑” 的分离，后续新增乘法、除法只需添加新的回调函数，无需修改<code>calculate</code>。</li></ul><br><br><h4>二、模拟 GUI 事件消息（按钮点击、文本输入）</h4><br><br><p><strong>机制</strong>：用户操作（如点击按钮）触发事件，回调函数响应事件。C 语言无原生 GUI 库，此处用输入模拟事件。</p><br><br><p>c</p><br><br><pre><br><code class="language-cpp">#include <stdio.h><br>#include <string.h><br><br>// 回调函数类型：处理按钮点击（无参数）<br>typedef void (*ButtonCallback)();<br>// 回调函数类型：处理文本输入（带字符串参数）<br>typedef void (*TextCallback)(const char*);<br><br>// 按钮回调函数：点击后提示<br>void onButtonClick() {<br>    printf("[GUI事件] 按钮被点击了！\n");<br>}<br><br>// 文本输入回调函数：打印输入内容<br>void onTextInput(const char* text) {<br>    printf("[GUI事件] 输入内容：%s\n", text);<br>}<br><br>// 模拟GUI组件：绑定回调并触发事件<br>void simulateGUI() {<br>    ButtonCallback btnCallback = onButtonClick;<br>    TextCallback textCallback = onTextInput;<br><br>    // 模拟用户操作：先点击按钮，再输入文本<br>    printf("请输入操作（1=点击按钮，2=输入文本）：");<br>    int op;<br>    scanf("%d", &op);<br>    if (op == 1) {<br>        btnCallback();  // 触发按钮事件<br>    } else if (op == 2) {<br>        printf("请输入文本：");<br>        char text[100];<br>        scanf("%s", text);<br>        textCallback(text);  // 触发文本输入事件<br>    }<br>}<br><br>int main() {<br>    simulateGUI();<br>    return 0;<br>}<br></code></pre><br><br><p><strong>解释</strong>：</p><br><br><ul><li>定义两种回调类型分别处理 “无参数事件”（按钮点击）和 “带参数事件”（文本输入）。</li><li><code>simulateGUI</code>函数模拟 GUI 框架的事件绑定逻辑，用户操作通过输入触发，最终调用对应的回调函数响应。</li></ul><br><br><h4>三、模拟网络请求消息（异步回调）</h4><br><br><p><strong>机制</strong>：网络请求耗时，通过多线程模拟异步操作，请求完成后调用回调处理响应。</p><br><br><p>c</p><br><br><pre><br><code class="language-cpp">#include <stdio.h><br>#include <pthread.h><br>#include <stdlib.h><br>#include <string.h><br><br>// 网络响应结构体：模拟HTTP响应数据<br>typedef struct {<br>    int status_code;  // 状态码（200=成功，404=失败）<br>    char content[1024];  // 响应内容<br>} HttpResponse;<br><br>// 回调函数类型：处理网络响应<br>typedef void (*HttpCallback)(HttpResponse*);<br><br>// 回调函数：处理成功/失败的响应<br>void handleHttpResponse(HttpResponse* resp) {<br>    if (resp->status_code == 200) {<br>        printf("[网络响应] 成功！内容：%s\n", resp->content);<br>    } else {<br>        printf("[网络响应] 失败！状态码：%d\n", resp->status_code);<br>    }<br>    free(resp);  // 释放动态分配的响应内存<br>}<br><br>// 线程函数：模拟异步网络请求（内部调用回调）<br>void* asyncRequest(void* arg) {<br>    HttpCallback callback = (HttpCallback)arg;  // 获取回调函数<br><br>    // 模拟网络请求耗时（1秒）<br>    printf("[网络请求] 正在发送请求...\n");<br>    sleep(1);<br><br>    // 构造响应数据（模拟成功/失败）<br>    HttpResponse* resp = (HttpResponse*)malloc(sizeof(HttpResponse));<br>    resp->status_code = 200;  // 可改为404测试失败场景<br>    strcpy(resp->content, "这是服务器返回的数据");<br><br>    // 请求完成，调用回调处理结果<br>    callback(resp);<br>    return NULL;<br>}<br><br>// 发送异步请求的接口<br>void sendRequest(HttpCallback callback) {<br>    pthread_t tid;<br>    // 创建线程执行异步请求，传入回调函数作为参数<br>    pthread_create(&tid, NULL, asyncRequest, (void*)callback);<br>    pthread_detach(tid);  // 线程分离，自动释放资源<br>}<br><br>int main() {<br>    sendRequest(handleHttpResponse);<br>    printf("[主线程] 请求已发送，继续执行其他任务...\n");<br>    sleep(2);  // 等待异步任务完成（实际开发中无需主动sleep）<br>    return 0;<br>}<br></code></pre><br><br><p><strong>编译运行</strong>：需链接 pthread 库（<code>gcc test.c -o test -lpthread</code>）。</p><br><br><p><strong>解释</strong>：</p><br><br><ul><li>用<code>pthread</code>模拟异步网络请求，主线程调用<code>sendRequest</code>后不阻塞，继续执行其他逻辑。</li><li>网络请求完成后，在子线程中调用<code>handleHttpResponse</code>回调函数处理响应，实现 “请求发起” 与 “结果处理” 的异步解耦。</li></ul><br><br><h4>四、设备状态机消息（状态变更回调）</h4><br><br><p><strong>机制</strong>：设备状态（启动、运行、故障）变更时，通过回调通知并处理对应状态。</p><br><br><p>c</p><br><br><pre><br><code class="language-cpp">#include <stdio.h><br><br>// 状态枚举：定义设备可能的状态<br>typedef enum {<br>    STATE_START,    // 启动<br>    STATE_RUNNING,  // 运行<br>    STATE_ERROR     // 故障<br>} DeviceState;<br><br>// 回调函数类型：处理不同状态（带参数）<br>typedef void (*StateCallback)(int param);  // param：状态参数（如速度、错误码）<br><br>// 状态回调函数：启动状态（无参数，param忽略）<br>void onStart(int unused) {<br>    printf("[设备状态] 启动中：初始化传感器...\n");<br>}<br><br>// 状态回调函数：运行状态（param=速度）<br>void onRunning(int speed) {<br>    printf("[设备状态] 运行中：当前速度 %d rpm\n", speed);<br>}<br><br>// 状态回调函数：故障状态（param=错误码）<br>void onError(int errorCode) {<br>    printf("[设备状态] 故障：错误码 %d，请检修！\n", errorCode);<br>}<br><br>// 设备结构体：存储状态和对应回调<br>typedef struct {<br>    StateCallback callbacks[3];  // 索引对应State枚举<br>} Device;<br><br>// 初始化设备：绑定状态与回调<br>void deviceInit(Device* dev) {<br>    dev->callbacks[STATE_START] = onStart;<br>    dev->callbacks[STATE_RUNNING] = onRunning;<br>    dev->callbacks[STATE_ERROR] = onError;<br>}<br><br>// 变更设备状态：触发对应回调<br>void deviceSetState(Device* dev, DeviceState state, int param) {<br>    if (state >= 0 && state < 3) {  // 检查状态合法性<br>        dev->callbacks[state](param);  // 调用对应回调并传递参数<br>    }<br>}<br><br>int main() {<br>    Device dev;<br>    deviceInit(&dev);<br><br>    // 模拟设备状态变更<br>    deviceSetState(&dev, STATE_START, 0);       // 启动<br>    deviceSetState(&dev, STATE_RUNNING, 3000);  // 运行（速度3000）<br>    deviceSetState(&dev, STATE_ERROR, 502);     // 故障（错误码502）<br>    return 0;<br>}<br></code></pre><br><br><p><strong>解释</strong>：</p><br><br><ul><li>用枚举<code>DeviceState</code>定义设备状态，结构体<code>Device</code>存储每个状态对应的回调函数。</li><li><code>deviceSetState</code>函数根据状态索引调用对应回调，实现 “状态变更” 与 “状态处理” 的分离，新增状态只需添加枚举和回调，无需修改状态机核心逻辑。</li></ul><br><br><h4>五、消息队列（生产者 - 消费者模型）</h4><br><br><p><strong>机制</strong>：生产者生产消息放入队列，消费者线程循环取消息并通过回调处理。</p><br><br><p>c</p><br><br><pre><br><code class="language-cpp">#include <stdio.h><br>#include <pthread.h><br>#include <stdlib.h><br>#include <string.h><br>#include <unistd.h><br><br>#define QUEUE_SIZE 5  // 队列最大容量<br><br>// 消息结构体<br>typedef struct {<br>    char data[100];  // 消息内容<br>} Message;<br><br>// 消息队列结构体<br>typedef struct {<br>    Message queue[QUEUE_SIZE];<br>    int front;       // 队头索引<br>    int rear;        // 队尾索引<br>    int count;       // 当前消息数<br>    pthread_mutex_t mutex;  // 互斥锁（保护队列操作）<br>    pthread_cond_t cond;    // 条件变量（通知消费者）<br>} MessageQueue;<br><br>// 回调函数类型：处理消息<br>typedef void (*MessageCallback)(const Message*);<br><br>// 初始化消息队列<br>void queueInit(MessageQueue* q) {<br>    q->front = 0;<br>    q->rear = 0;<br>    q->count = 0;<br>    pthread_mutex_init(&q->mutex, NULL);<br>    pthread_cond_init(&q->cond, NULL);<br>}<br><br>// 入队操作（生产者调用）<br>void queuePush(MessageQueue* q, const Message* msg) {<br>    pthread_mutex_lock(&q->mutex);<br>    // 等待队列非满<br>    while (q->count == QUEUE_SIZE) {<br>        pthread_cond_wait(&q->cond, &q->mutex);<br>    }<br>    // 放入消息<br>    strcpy(q->queue[q->rear].data, msg->data);<br>    q->rear = (q->rear + 1) % QUEUE_SIZE;<br>    q->count++;<br>    pthread_cond_signal(&q->cond);  // 通知消费者<br>    pthread_mutex_unlock(&q->mutex);<br>}<br><br>// 出队操作（消费者调用）<br>int queuePop(MessageQueue* q, Message* msg) {<br>    pthread_mutex_lock(&q->mutex);<br>    // 等待队列非空<br>    while (q->count == 0) {<br>        pthread_cond_wait(&q->cond, &q->mutex);<br>    }<br>    // 取出消息<br>    strcpy(msg->data, q->queue[q->front].data);<br>    q->front = (q->front + 1) % QUEUE_SIZE;<br>    q->count--;<br>    pthread_cond_signal(&q->cond);  // 通知生产者<br>    pthread_mutex_unlock(&q->mutex);<br>    return 1;<br>}<br><br>// 消息处理回调函数<br>void processMessage(const Message* msg) {<br>    printf("[消费消息] 处理：%s（耗时1秒）\n", msg->data);<br>    sleep(1);  // 模拟处理耗时<br>}<br><br>// 消费者线程函数：循环取消息并调用回调<br>void* consumer(void* arg) {<br>    MessageQueue* q = (MessageQueue*)arg;<br>    Message msg;<br>    while (1) {<br>        queuePop(q, &msg);<br>        // 检查退出消息<br>        if (strcmp(msg.data, "exit") == 0) {<br>            printf("[消费者] 收到退出信号，停止运行\n");<br>            break;<br>        }<br>        processMessage(&msg);  // 调用回调处理消息<br>    }<br>    return NULL;<br>}<br><br>// 生产者：生成消息并放入队列<br>void producer(MessageQueue* q) {<br>    Message msgs[4] = {<br>        {"消息1：设备温度正常"},<br>        {"消息2：电压稳定"},<br>        {"消息3：网络连接成功"},<br>        {"exit"}  // 退出信号<br>    };<br>    for (int i = 0; i < 4; i++) {<br>        printf("[生产消息] 发送：%s\n", msgs[i].data);<br>        queuePush(q, &msgs[i]);<br>        sleep(0.5);  // 模拟间隔生产<br>    }<br>}<br><br>int main() {<br>    MessageQueue q;<br>    queueInit(&q);<br><br>    // 启动消费者线程<br>    pthread_t tid;<br>    pthread_create(&tid, NULL, consumer, &q);<br><br>    // 生产者生产消息<br>    producer(&q);<br><br>    // 等待消费者结束<br>    pthread_join(tid, NULL);<br><br>    // 清理资源<br>    pthread_mutex_destroy(&q->mutex);<br>    pthread_cond_destroy(&q->cond);<br>    return 0;<br>}<br></code></pre><br><br><p><strong>编译运行</strong>：<code>gcc queue.c -o queue -lpthread</code></p><br><br><p><strong>解释</strong>：</p><br><br><ul><li>消息队列通过互斥锁（<code>mutex</code>）和条件变量（<code>cond</code>）实现线程安全，生产者和消费者异步操作。</li><li>消费者线程取出消息后，调用<code>processMessage</code>回调函数处理，实现 “消息生产” 与 “消息处理” 的解耦。若需更换处理逻辑，只需修改回调函数，无需修改队列或生产者代码。</li></ul><br><br><h4>总结</h4><br><br><p>C 语言中回调函数通过<strong>函数指针</strong>实现，核心价值在于：</p><br><br><ol><li><strong>解耦</strong>：将 “触发逻辑” 与 “处理逻辑” 分离（如网络请求与响应处理）。</li><li><strong>灵活性</strong>：同一触发点可绑定不同回调，实现多样化处理（如状态机的多状态响应）。</li><li><strong>异步支持</strong>：结合多线程，可在异步操作（网络、IO）完成后通知结果。</li></ol><br><br><p>不同消息机制的回调写法差异主要体现在<strong>参数设计</strong>（如带状态参数、带数据结构体）和<strong>触发时机</strong>（如事件发生、异步完成），但核心都是通过函数指针实现动态逻辑注入。</p><br>
