<p>在 Python 中，你可以使用内置的 <code>pow()</code> 函数来高效地计算幂运算和取模运算。以下是计算 2 的 100 次方对 5 取模的代码：</p> <br><pre><code class="language-python">result = pow(2, 100, 5)<br>print(result)</code></pre> <br><p>上述代码中，<code>pow()</code> 函数的第一个参数是底数，第二个参数是指数，第三个参数是模数。它会直接计算出幂运算结果对模数取模的值。运行代码后，会打印出最终结果。</p> <br><p>在数字没有超出int大小范围时，可以用以下代码计算</p> <br><pre><code class="language-cpp">#include <br><p> <code>exponent</code> 相关计算，其实是在快速幂算法里的操作，目的是高效地算出一个数的幂次。下面详细解释下 <code>exponent</code> 在代码里是如何被计算的，以及这么做的原因。</p> <br><h4>快速幂算法原理</h4> <br><p>快速幂算法的核心思路是把指数 <code>exponent</code> 用二进制形式来表示，进而把幂运算转化成一系列的平方和乘法操作。这可以显著减少乘法运算的次数，让时间复杂度从常规幂运算的 (O(n)) 降低到 (O(log n))。</p> <br><h4>代码中 <code>exponent</code> 的计算步骤</h4> <br><p>下面是代码片段：</p> <br><pre><code class="language-cpp">while (exponent > 0) {<br>    if (exponent % 2 == 1) {<br>        result = (result * base) % modulus;<br>    }<br>    exponent = exponent / 2;<br>    base = (base * base) % modulus;<br>}</code></pre> <br><h5>1. 判断 <code>exponent</code> 是否为奇数</h5> <br><p>c</p> <br><pre><code class="language-cpp">if (exponent % 2 == 1) {<br>    result = (result * base) % modulus;<br>}<br></code></pre> <br><p></p> <br><ul><li><code>exponent % 2 == 1</code> 用于判断 <code>exponent</code> 是否为奇数。在二进制表示中，奇数的最低位是 1，偶数的最低位是 0。</li><li>若 <code>exponent</code> 为奇数，就意味着当前二进制位是 1，需要把当前的 <code>base</code> 乘到结果 <code>result</code> 里，并且取模以避免溢出。</li></ul> <br><h5>2. 指数右移（除以 2）</h5> <br><p>c</p> <br><pre><code class="language-cpp">exponent = exponent / 2;<br></code></pre> <br><p></p> <br><ul><li>这行代码把 <code>exponent</code> 除以 2，等同于将 <code>exponent</code> 的二进制表示向右移一位。这样做是为了处理下一个二进制位。</li></ul> <br><h5>3. 底数平方</h5> <br><p>c</p> <br><pre><code class="language-cs">base = (base * base) % modulus;<br></code></pre> <br><p></p> <br><ul><li>每次循环时，<code>base</code> 都会平方。这是因为随着指数右移，每一位对应的幂次都是前一位的平方。例如，(2^2 = 4)，(2^4 = 16)，(2^8 = 256) 等。</li><li>同样要进行取模操作，防止溢出。</li></ul> <br><h4>示例</h4> <br><p>假设要计算 (2^{10})，10 的二进制表示是 <code>1010</code>。</p> <br><ul><li>初始时，<code>base = 2</code>，<code>exponent = 10</code>，<code>result = 1</code>。</li><li>第一次循环： <br>  <ul><li><code>exponent = 10</code> 是偶数，不更新 <code>result</code>。</li><li><code>exponent</code> 除以 2 后变为 5。</li><li><code>base</code> 平方变为 (2^2 = 4)。</li></ul> </li><li>第二次循环： <br>  <ul><li><code>exponent = 5</code> 是奇数，<code>result = result * base = 1 * 4 = 4</code>。</li><li><code>exponent</code> 除以 2 后变为 2。</li><li><code>base</code> 平方变为 (4^2 = 16)。</li></ul> </li><li>第三次循环： <br>  <ul><li><code>exponent = 2</code> 是偶数，不更新 <code>result</code>。</li><li><code>exponent</code> 除以 2 后变为 1。</li><li><code>base</code> 平方变为 (16^2 = 256)。</li></ul> </li><li>第四次循环： <br>  <ul><li><code>exponent = 1</code> 是奇数，<code>result = result * base = 4 * 256 = 1024</code>。</li><li><code>exponent</code> 除以 2 后变为 0，循环结束。</li></ul> </li></ul> <br><p>最终结果就是 (2^{10} = 1024)。</p>
