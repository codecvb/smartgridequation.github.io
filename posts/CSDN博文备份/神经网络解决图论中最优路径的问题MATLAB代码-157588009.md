<p style="text-align:center"><img alt="" src="https://i-blog.csdnimg.cn/direct/43c57f13c97442cb99e470880c22cff6.png" /></p><br><br><h4>解决思路</h4><br><br><p>我们选择<strong>离散 Hopfield 神经网络</strong>来解决图的最短路径问题，核心思路是：</p><br><br><ol><li>将图的路径选择问题转化为神经网络的能量函数优化问题</li><li>能量函数的最小值对应最优路径（最短路径）</li><li>通过神经网络的迭代更新，让网络收敛到能量最小值</li><li>从收敛后的网络状态中解码出最优路径</li></ol><br><br><pre><br><code class="language-Matlab">% ==============================<br>% 基于Hopfield神经网络的随机位置多节点全遍历求解<br>% 功能：随机生成节点位置+多节点全遍历路径求解+可视化<br>% ==============================<br>clear; clc; close all;<br>rng(123); % 设置随机种子，保证结果可复现（可注释掉获取不同随机结果）<br><br>%% 1. 自定义参数设置<br>node_num = 20;          % 节点数量（可自行调整，建议10-20个）<br>start_node = 1;         % 起点<br>connect_prob = 0.4;     % 节点间连接概率（控制图的稀疏度，0.3-0.5为宜）<br>min_edge_length = 1;    % 最小边长度<br>max_edge_length = 10;   % 最大边长度<br><br>% 神经网络参数（适配多节点）<br>T = 5000;               % 最大迭代次数（节点越多需越大）<br>tau = 0.005;            % 时间步长（更小的值提升收敛精度）<br>beta = 80;              % 增益系数（增强约束强度）<br><br>%% 2. 随机生成节点位置和邻接矩阵<br>% 2.1 随机生成节点坐标（x,y），范围[0,20]<br>node_pos = rand(node_num, 2) * 20; <br><br>% 2.2 生成连通的邻接矩阵（保证图连通，避免无法遍历）<br>adj_matrix = zeros(node_num);<br>% 先构建最小生成树保证连通性<br>for i = 2:node_num<br>    j = randi(i-1); % 随机连接到前面的节点<br>    edge_len = min_edge_length + rand()*(max_edge_length - min_edge_length);<br>    adj_matrix(i,j) = edge_len;<br>    adj_matrix(j,i) = edge_len;<br>end<br>% 随机添加额外边<br>for i = 1:node_num<br>    for j = i+1:node_num<br>        if adj_matrix(i,j) == 0 && rand() < connect_prob<br>            edge_len = min_edge_length + rand()*(max_edge_length - min_edge_length);<br>            adj_matrix(i,j) = edge_len;<br>            adj_matrix(j,i) = edge_len;<br>        end<br>    end<br>end<br><br>n = node_num; % 节点总数<br>if n < 2<br>    error('节点数需大于等于2');<br>end<br><br>%% 3. Hopfield神经网络初始化<br>N = n * n;  % 网络神经元总数<br>V = zeros(n, n);  % 状态矩阵 V(i,j)=1表示第j步到达节点i<br>V(start_node, 1) = 1; % 起点初始化<br><br>%% 4. 定义能量函数的权重矩阵和偏置（适配多节点）<br>W = zeros(N);<br>for i = 1:n<br>    for j = 1:n<br>        for k = 1:n<br>            for l = 1:n<br>                idx1 = (j-1)*n + i;<br>                idx2 = (l-1)*n + k;<br>                <br>                % 约束1：路径连续性（仅允许邻接节点跳转）<br>                if j == l-1  % 前一步→当前步<br>                    if adj_matrix(k,i) == 0 && k~=i  % 无直接连接的节点惩罚<br>                        W(idx1, idx2) = W(idx1, idx2) + beta * 3;<br>                    else  % 邻接节点奖励（边越短奖励越大）<br>                        W(idx1, idx2) = W(idx1, idx2) - adj_matrix(k,i)/2;<br>                    end<br>                end<br>                <br>                % 约束2：单步长约束（每一步只能在一个节点）<br>                if i == k && j == l<br>                    W(idx1, idx2) = W(idx1, idx2) - beta;<br>                end<br>                <br>                % 约束3：单节点约束（每个节点仅出现一次）<br>                if i == k && j ~= l<br>                    W(idx1, idx2) = W(idx1, idx2) - beta * 2;<br>                end<br>                <br>                % 约束4：无效步长惩罚（避免非连续步长激活）<br>                if abs(j - l) > 1 && i == k<br>                    W(idx1, idx2) = W(idx1, idx2) + beta;<br>                end<br>            end<br>        end<br>    end<br>end<br><br>% 偏置向量b（强化约束）<br>b = zeros(N, 1);<br>b((1-1)*n + start_node) = beta * n; % 起点约束<br>% 全节点覆盖约束<br>for i = 1:n<br>    b((1:n-1)*n + i) = b((1:n-1)*n + i) + beta/2;<br>end<br><br>%% 5. 神经网络迭代更新<br>energy_history = [];<br>converge_flag = false;<br>for t = 1:T<br>    % 计算神经元输入<br>    u = W * V(:) + b;<br>    <br>    % Sigmoid激活函数<br>    V_new = 1 ./ (1 + exp(-u/tau));<br>    <br>    % 二值化处理<br>    V_new(V_new >= 0.5) = 1;<br>    V_new(V_new < 0.5) = 0;<br>    V_new = reshape(V_new, n, n);<br>    <br>    % 计算当前能量<br>    energy = -0.5 * V(:)' * W * V(:) - b' * V(:);<br>    energy_history = [energy_history, energy];<br>    <br>    % 收敛判断<br>    if sum(sum(abs(V_new - V))) < 1e-6<br>        disp(['迭代', num2str(t), '次后收敛']);<br>        V = V_new;<br>        converge_flag = true;<br>        break;<br>    end<br>    <br>    V = V_new;<br>    <br>    % 最大迭代次数提示<br>    if t == T<br>        disp('达到最大迭代次数，停止计算');<br>    end<br>end<br><br>%% 6. 路径解码（容错增强）<br>path = [];<br>current_node = start_node;<br>path = [path, current_node];<br>visited_nodes = zeros(1, n);<br>visited_nodes(start_node) = 1;<br><br>% 逐步解码路径<br>for step = 2:n<br>    next_node = 0;<br>    % 优先选择邻接且未访问的节点<br>    for node = 1:n<br>        if V(node, step) == 1 && visited_nodes(node) == 0 && adj_matrix(current_node, node) > 0<br>            next_node = node;<br>            break;<br>        end<br>    end<br>    % 容错1：放宽状态矩阵约束<br>    if next_node == 0<br>        for node = 1:n<br>            if visited_nodes(node) == 0 && adj_matrix(current_node, node) > 0<br>                next_node = node;<br>                break;<br>            end<br>        end<br>    end<br>    % 容错2：允许访问已访问节点（避免路径断裂）<br>    if next_node == 0<br>        for node = 1:n<br>            if adj_matrix(current_node, node) > 0<br>                next_node = node;<br>                disp(['警告：节点', num2str(current_node), '无未访问邻接节点，复用节点', num2str(next_node)]);<br>                break;<br>            end<br>        end<br>    end<br>    <br>    if next_node == 0<br>        disp('错误：无法找到有效后续节点，路径中断');<br>        break;<br>    end<br>    <br>    path = [path, next_node];<br>    if visited_nodes(next_node) == 0<br>        visited_nodes(next_node) = 1;<br>    end<br>    current_node = next_node;<br>end<br><br>% 计算路径总长度<br>total_length = 0;<br>for i = 1:length(path)-1<br>    total_length = total_length + adj_matrix(path(i), path(i+1));<br>end<br><br>%% 7. 结果展示<br>disp('=== 多节点全遍历求解结果 ===');<br>disp(['节点总数：', num2str(n)]);<br>disp(['起点：', num2str(start_node)]);<br>disp(['遍历路径：', num2str(path)]);<br>disp(['路径总长度：', num2str(round(total_length, 2))]);<br>disp(['遍历节点数：', num2str(length(path)), '/', num2str(n)]);<br>disp(['未访问节点：', num2str(find(visited_nodes == 0))]);<br><br>%% 8. 可视化（适配随机位置）<br>% 8.1 能量变化曲线<br>figure('Color','w','Position',[100,100,800,400]);<br>plot(energy_history, 'LineWidth',1.5,'Color','#2E86AB');<br>xlabel('迭代次数','FontSize',12);<br>ylabel('能量值','FontSize',12);<br>title(['能量变化曲线（节点数：', num2str(n), '）'],'FontSize',14);<br>grid on; grid minor;<br><br>% 8.2 随机节点+遍历路径可视化<br>figure('Color','w','Position',[200,200,800,600]);<br>% 绘制所有边<br>hold on;<br>for i = 1:n<br>    for j = i+1:n<br>        if adj_matrix(i,j) > 0<br>            plot([node_pos(i,1), node_pos(j,1)], [node_pos(i,2), node_pos(j,2)], ...<br>                 'k--','LineWidth',0.8,'Color',[0.7,0.7,0.7]);<br>        end<br>    end<br>end<br>% 绘制节点<br>scatter(node_pos(:,1), node_pos(:,2), 100, 'ro', 'filled','MarkerEdgeColor','k');<br>% 标注节点编号<br>for i = 1:n<br>    text(node_pos(i,1)+0.2, node_pos(i,2)+0.2, num2str(i), ...<br>         'FontSize',11,'FontWeight','bold');<br>end<br>% 绘制遍历路径<br>for i = 1:length(path)-1<br>    plot([node_pos(path(i),1), node_pos(path(i+1),1)], ...<br>         [node_pos(path(i),2), node_pos(path(i+1),2)], ...<br>         'r-','LineWidth',2.5,'Color','#A23B72');<br>    % 标注步长<br>    mid_x = (node_pos(path(i),1) + node_pos(path(i+1),1))/2;<br>    mid_y = (node_pos(path(i),2) + node_pos(path(i+1),2))/2;<br>    text(mid_x, mid_y, num2str(i), 'FontSize',9,'Color','blue','FontWeight','bold');<br>end<br>% 标注起点<br>plot(node_pos(start_node,1), node_pos(start_node,2), 'gs', 'MarkerSize',12,'LineWidth',2);<br>text(node_pos(start_node,1)-0.5, node_pos(start_node,2)-0.5, '起点', ...<br>     'FontSize',10,'Color','green','FontWeight','bold');<br>axis equal;<br>xlabel('X坐标','FontSize',12);<br>ylabel('Y坐标','FontSize',12);<br>title(['随机位置多节点遍历路径（节点数：', num2str(n), '）'],'FontSize',14);<br>box on;<br>hold off;<br><br>% 8.3 输出节点位置信息<br>disp('=== 节点位置坐标 ===');<br>for i = 1:n<br>    disp(['节点', num2str(i), '：(', num2str(round(node_pos(i,1),2)), ', ', num2str(round(node_pos(i,2),2)), ')']);<br>end</code></pre><br><br><h4>代码关键说明</h4><br><br><ol><li><br>	<p><strong>随机节点生成</strong>：</p><br><br>	<ul><li><code>node_pos = rand(node_num, 2) * 20</code> 生成 0-20 范围内的随机坐标；</li><li>设置<code>rng(123)</code>固定随机种子，如需不同随机结果可注释该行；</li><li>可调整<code>node_num</code>（节点数）、<code>connect_prob</code>（连接概率）等参数。</li></ul><br>	</li><li><br>	<p><strong>邻接矩阵生成</strong>：</p><br><br>	<ul><li>先构建最小生成树保证图的连通性，避免无法遍历；</li><li>再随机添加额外边，控制图的稀疏度；</li><li>边长度随机生成在<code>min_edge_length</code>和<code>max_edge_length</code>之间。</li></ul><br>	</li><li><br>	<p><strong>多节点适配</strong>：</p><br><br>	<ul><li>增大迭代次数<code>T=5000</code>、增益系数<code>beta=80</code>，适配更多节点的计算需求；</li><li>优化能量函数惩罚 / 奖励权重，提升收敛稳定性；</li><li>增强路径解码的容错机制，避免路径断裂。</li></ul><br>	</li><li><br>	<p><strong>可视化优化</strong>：</p><br><br>	<ul><li>绘制随机坐标的节点和路径，标注起点、步长、节点编号；</li><li>输出节点位置坐标，便于核对；</li><li>能量曲线和路径图分开绘制，布局更清晰。</li></ul><br>	</li></ol><br><br><h4>使用建议</h4><br><br><ul><li>节点数建议先从
