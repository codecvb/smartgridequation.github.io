<p><span style="color:#ff9900;">以下是使用 Python 和 OpenCV 将 MP4 转换为 GIF 的示例代码：</span></p> <br><p>python</p> <br><pre><code class="language-python">import cv2<br>import imageio<br><br>def mp4_to_gif(mp4_path, gif_path, fps=10, start_time=None, end_time=None):<br>    """<br>    将MP4视频转换为GIF动图。<br><br>    :param mp4_path: 输入MP4视频的路径。<br>    :param gif_path: 输出GIF文件的路径。<br>    :param fps: GIF的帧率，默认值为10。<br>    :param start_time: 开始时间（秒），默认值为None，表示从视频开头开始转换。<br>    :param end_time: 结束时间（秒），默认值为None，表示转换到视频结尾。<br>    """<br>    cap = cv2.VideoCapture(mp4_path)<br>    all_images = []<br>    frame_count = 0<br>    while True:<br>        ret, img = cap.read()<br>        if not ret:<br>            break<br>        # 根据开始时间和结束时间截取帧<br>        if start_time is not None and frame_count < start_time * fps:<br>            frame_count += 1<br>            continue<br>        if end_time is not None and frame_count >= end_time * fps:<br>            break<br>        # 将BGR图像转换为RGB格式，以适应imageio保存GIF的要求<br>        img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)<br>        all_images.append(img)<br>        frame_count += 1<br><br>    # 将帧率转换为每帧之间的延迟时间（毫秒）<br>    duration = int(1000 / fps)<br>    imageio.mimsave(gif_path, all_images, duration=duration)<br>    print("转换完成！")<br><br>if __name__ == "__main__":<br>    input_mp4_path = "your_input_mp4.mp4"  # 替换为实际的输入MP4视频路径<br>    output_gif_path = "output.gif"  # 替换为输出GIF文件的路径<br>    start_time = 0  # 开始时间，单位：秒，可根据需要修改<br>    end_time = 5  # 结束时间，单位：秒，可根据需要修改<br>    fps = 15  # GIF的帧率，可根据需要修改<br><br>    mp4_to_gif(input_mp4_path, output_gif_path, fps=fps, start_time=start_time, end_time=end_time)<br></code></pre> <br><p></p> <br><p>在上述代码中：</p> <br><h4>读取视频帧</h4> <br><p></p> <br><ul><li>首先使用<code>cv2.VideoCapture</code>函数打开指定的 MP4 视频文件，并创建一个视频捕获对象<code>cap</code>2.</li><li>通过一个循环不断读取视频的帧，使用<code>cap.read()</code>函数读取视频的下一帧图像。如果读取失败（视频结束），则跳出循环2.</li></ul> <br><h4>截取特定时间段的帧</h4> <br><p></p> <br><ul><li>根据提供的<code>start_time</code>和<code>end_time</code>参数来控制要转换的帧范围。如果<code>start_time</code>不为<code>None</code>，并且当前帧索引小于<code>start_time</code>乘以帧率的值，则跳过该帧。如果<code>end_time</code>不为<code>None</code>，并且当前帧索引大于等于<code>end_time</code>乘以帧率的值，则跳出循环2.</li></ul> <br><h4>转换图像格式</h4> <br><p></p> <br><ul><li>使用<code>cv2.cvtColor</code>函数将读取的图像帧从 BGR 格式转换为 RGB 格式，以便后续生成 GIF 图片时颜色显示正确2.</li></ul> <br><h4>保存为 GIF</h4> <br><p></p> <br><ul><li>将转换后的图像帧添加到<code>all_images</code>列表中。</li><li>根据提供的帧率<code>fps</code>计算每帧之间的延迟时间<code>duration</code>，以便生成的 GIF 图片播放时具有指定的帧率2.</li><li>使用<code>imageio.mimsave</code>函数将<code>all_images</code>列表中的帧保存为 GIF 图片。指定参数<code>duration</code>为帧间延迟时间。保存的 GIF 图片文件名由提供的<code>gif_path</code>参数决定2.</li></ul> <br><p></p> <br><p>在运行代码之前，需要先安装<code>opencv-python</code>和<code>imageio</code>库，可以通过<code>pip install opencv-python imageio</code>命令进行安装1. 同时，要将代码中的输入 MP4 视频路径、输出 GIF 文件路径、开始时间、结束时间和帧率等参数按照实际需求进行替换 。</p> <br><p>效果如下</p> <br><p style="text-align:center;"><img alt="" src="https://i-blog.csdnimg.cn/direct/4fc5f546c547414f8927ff9d511fd0b4.gif" /></p>
