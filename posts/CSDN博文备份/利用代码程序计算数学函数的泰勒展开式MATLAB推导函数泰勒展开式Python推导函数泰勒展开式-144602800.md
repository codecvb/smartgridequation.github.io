<h2><span style="color:#a2e043;">以下代码均经过博主验证</span></h2> <br><h2><span style="color:#fe2c24;">一、Python推导函数泰勒展开式</span></h2> <br><p>在 Python 中，可以借助 <code>sympy</code> 库来推导函数的泰勒展开式，以下是一个示例代码，以推导 <code>sin(x)</code> 函数的泰勒展开式为例来说明步骤：</p> <br><h3 style="background-color:transparent;">1. 安装 <code>sympy</code> 库（如果还未安装的话）</h3> <br><p>如果使用的是 <code>pip</code> 包管理工具，可以在命令行执行以下命令安装：</p> <br><pre><code>pip install sympy -i https://pypi.mirrors.ustc.edu.cn/simple<br></code></pre> <br><h3>2. Python 代码示例</h3> <br><p>python</p> <br><pre><code class="language-python">import sympy<br><br># 定义变量<br>x = sympy.Symbol('x')<br># 定义函数，这里以sin(x)为例<br>func = sympy.sin(x)<br># 求泰勒展开式，参数依次为：函数、展开的变量、展开的点、展开的阶数<br>taylor_expansion = func.series(x, 0, 10)<br>print(taylor_expansion.removeO())<br></code></pre> <br><p>在上述代码中：</p> <br><ul><li>首先通过 <code>sympy.Symbol('x')</code> 定义了符号变量 <code>x</code>，这是后续进行符号运算的基础。</li><li>接着定义了想要展开的函数，这里定义了 <code>sympy.sin(x)</code>，你可以将其替换为其他你想要展开的函数，比如 <code>sympy.cos(x)</code>、<code>sympy.exp(x)</code> 等等。</li><li>然后调用 <code>series</code> 方法来求泰勒展开式，它接受几个关键参数： <br>  <ul><li>第一个参数是要展开的函数（这里就是前面定义的 <code>func</code>）。</li><li>第二个参数指定展开的变量，也就是基于哪个变量进行展开（这里是 <code>x</code>）。</li><li>第三个参数是展开的点，也就是在哪个值附近展开，这里 <code>0</code> 表示在 <code>x = 0</code> 附近展开（通常称为麦克劳林展开，是泰勒展开在展开点为 0 时的特殊情况）。</li><li>第四个参数是展开的阶数，示例中设置为 <code>10</code>，表示展开到 <code>x</code> 的 10 阶项。</li></ul></li><li>最后，因为返回的结果中包含了表示高阶无穷小的 <code>O(x**10)</code> 这样的形式，调用 <code>removeO()</code> 方法将其去除，得到更简洁的泰勒展开式的表达式呈现。</li></ul> <br><p>你可以根据实际需求，修改函数以及相关参数，比如改变展开的点、展开的阶数等，来获取不同情况下函数的泰勒展开式。</p> <br><h3>3.案例如下</h3> <br><pre><code class="language-python">import sympy<br><br># 定义变量<br>x = sympy.Symbol('x')<br># 定义函数，这里以sin(x)为例<br>func = sympy.sin(x)+sympy.cos(x)<br># 求泰勒展开式，参数依次为：函数、展开的变量、展开的点、展开的阶数<br>taylor_expansion = func.series(x, 0, 10)<br>print(taylor_expansion.removeO())</code></pre> <br><p>推导出的泰勒展开式</p> <br><pre><code class="language-Matlab">x**9/362880 + x**8/40320 - x**7/5040 - x**6/720 + x**5/120 + x**4/24 - x**3/6 - x**2/2 + x + 1</code></pre> <br><h2><span style="color:#fe2c24;">二、MATLAB推导函数泰勒展开式</span></h2> <br><p>在 MATLAB 中，可以使用 <code>taylor</code> 函数来推导函数的泰勒展开式，以下是具体的使用方法及示例：</p> <br><h4>1. 基本语法</h4> <br><p><code>taylor(f,x,a,'Order',n)</code></p> <br><ul><li><code>f</code>：表示需要进行泰勒展开的函数表达式，可以是一个符号函数（通过 <code>syms</code> 定义符号变量后构建的函数）。</li><li><code>x</code>：指定展开所依据的变量。</li><li><code>a</code>：展开的中心点，也就是在该点附近进行泰勒展开，当 <code>a = 0</code> 时，就是常见的麦克劳林展开。</li><li><code>'Order',n</code>：这是可选参数，用于指定泰勒展开的阶数为 <code>n</code>（即展开到 <code>x</code> 的 <code>n-1</code> 次幂项），如果不写这个参数，MATLAB 会使用默认的阶数。</li></ul> <br><h4>2. 示例代码</h4> <br><p>以下以推导函数 <code>sin(x)</code> 在 <code>x = 0</code> 附近（麦克劳林展开）的泰勒展开式为例：</p> <br><p>matlab</p> <br><pre><code class="language-Matlab">% 定义符号变量<br>syms x;<br>% 定义函数<br>f = sin(x);<br>% 求泰勒展开式，这里求到5阶（即展开到x的4次幂项）<br>taylor_expansion = taylor(f,x,0,'Order',5);<br>disp(taylor_expansion);<br></code></pre> <br><p>在上述代码中：</p> <br><ul><li>首先通过 <code>syms x</code> 定义了符号变量 <code>x</code>，这是进行符号运算的基础，后续定义的函数都基于这个符号变量。</li><li>接着定义了函数 <code>f</code> 为 <code>sin(x)</code>，你可以将其替换成其他想要展开的函数，比如 <code>cos(x)</code>、<code>exp(x)</code> 等。</li><li>然后调用 <code>taylor</code> 函数来求泰勒展开式，这里指定了展开的中心点 <code>a = 0</code>，以及展开的阶数为 <code>5</code>，最后将得到的泰勒展开式结果输出显示。</li></ul> <br><p>如果想改变展开的函数、展开的中心点或者展开的阶数等，只需要修改对应代码中的参数即可。例如，若要推导 <code>cos(x)</code> 在 <code>x = pi/4</code> 附近展开到 8 阶的泰勒展开式，可以这样写：</p> <br><p>matlab</p> <br><pre><code class="language-Matlab">% 定义符号变量<br>syms x;<br>% 定义函数<br>f = cos(x);<br>% 求泰勒展开式，在x = pi/4附近展开到8阶<br>taylor_expansion = taylor(f,x,pi/4,'Order',8);<br>disp(taylor_expansion);<br></code></pre> <br><p>通过上述方式，就可以方便地利用 MATLAB 推导不同函数在不同条件下的泰勒展开式了。</p> <br><p>案例如下</p> <br><pre><code class="language-Matlab">% 定义符号变量<br>syms x;<br>% 定义函数<br>f = tan(x);<br>% 求泰勒展开式，在x = pi/4附近展开到8阶<br>taylor_expansion = taylor(f,x,0,'Order',8);<br>disp(taylor_expansion);</code></pre> <br><p>推导结果如下</p> <br><pre><code class="language-Matlab">(17*x^7)/315 + (2*x^5)/15 + x^3/3 + x</code></pre> <br><p>可以对比正确结果，完全无误</p> <br><p style="text-align:center;"><img alt=""
