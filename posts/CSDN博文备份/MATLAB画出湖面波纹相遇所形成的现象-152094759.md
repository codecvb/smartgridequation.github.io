<p>我们可以使用 MATLAB 来模拟和绘制湖面波纹相遇时产生的干涉现象。这是一个非常经典的物理现象，可以通过二维波动方程的叠加来实现。</p><br><br><p>下面是完整的 MATLAB 代码，它将模拟两个点波源产生的波纹在水面上传播并相遇的过程，并生成一个动态的 GIF 动画来展示这一现象。</p><br><br><p>本文介绍了一个使用MATLAB模拟湖面波纹干涉现象的完整代码。该程序通过定义两个点波源，计算其在二维空间产生的波纹传播，并叠加生成干涉图案。代码采用sinc函数模拟振幅衰减，避免奇点问题，并通过循环计算每一时刻的波面状态，最终生成动态GIF动画展示干涉过程。模拟参数包括波源位置、振幅、波长等可调变量，输出结果直观展示了波纹相遇时的干涉现象。该模拟适用于波动光学和水波干涉的教学演示。</p><br><br><p></p><br><br><p style="text-align:center"><img alt="" src="https://i-blog.csdnimg.cn/direct/3d6733c8a83342cf8ac26d03ededd45a.gif" /></p><br><br><h4>完整 MATLAB 代码</h4><br><br><pre><br><code class="language-Matlab">%% 湖面波纹干涉现象模拟<br><br>% 清理工作区<br>clear; clc; close all;<br><br>%% 1. 定义模拟参数<br>L = 100;                  % 模拟区域的大小 (L x L)<br>N = 200;                  % 网格点数，用于离散化空间<br>x = linspace(-L/2, L/2, N); % x轴坐标<br>y = linspace(-L/2, L/2, N); % y轴坐标<br>[X, Y] = meshgrid(x, y);   % 创建二维网格<br><br>% --- 波源参数 ---<br>S1 = [-20, 0];            % 第一个波源的坐标<br>S2 = [20, 0];             % 第二个波源的坐标<br>A = 1.0;                  % 波的振幅<br>lambda = 10;              % 波长<br>k = 2 * pi / lambda;      % 波数<br>omega = 2;                % 角频率<br><br>% --- 时间参数 ---<br>T_total = 20;             % 总模拟时间<br>Nt = 100;                 % 时间步数<br>t = linspace(0, T_total, Nt); % 时间数组<br><br>% 准备GIF动画<br>gif_filename = 'ripple_interference.gif';<br><br>%% 2. 循环计算并绘制每一帧<br>for i = 1:Nt<br>    % 当前时间<br>    current_t = t(i);<br>    <br>    % --- 计算两个波源产生的波 ---<br>    % r1 和 r2 是网格上任意一点到两个波源的距离<br>    r1 = sqrt((X - S1(1)).^2 + (Y - S1(2)).^2);<br>    r2 = sqrt((X - S2(1)).^2 + (Y - S2(2)).^2);<br>    <br>    % 计算每个波的相位和振幅<br>    % 使用 sinc 函数来避免在波源点 (r=0) 处出现无穷大，并模拟振幅随距离衰减<br>    wave1 = A * sinc(r1 / lambda) .* cos(k * r1 - omega * current_t);<br>    wave2 = A * sinc(r2 / lambda) .* cos(k * r2 - omega * current_t);<br>    <br>    % --- 波的叠加 (干涉) ---<br>    % 根据波的叠加原理，总位移是各个波位移的代数和<br>    total_wave = wave1 + wave2;<br>    <br>    % --- 绘制当前帧 ---<br>    figure(1);<br>    surf(X, Y, total_wave, 'EdgeColor', 'none');<br>    axis equal;<br>    axis([-L/2, L/2, -L/2, L/2, -2*A, 2*A]); % 限制坐标轴范围<br>    colormap('jet'); % 使用 jet 颜色图，蓝色表示波谷，红色表示波峰<br>    colorbar;<br>    title(sprintf('湖面波纹干涉 (t = %.2f s)', current_t));<br>    xlabel('X (cm)');<br>    ylabel('Y (cm)');<br>    zlabel('振幅');<br>    view(2); % 从上方俯视，更像看湖面<br>    drawnow;<br>    <br>    % --- 将当前帧写入GIF文件 ---<br>    frame = getframe(gcf);<br>    im = frame2im(frame);<br>    [imind, cm] = rgb2ind(im, 256);<br>    <br>    if i == 1<br>        imwrite(imind, cm, gif_filename, 'GIF', 'Loopcount', inf, 'DelayTime', 0.1);<br>    else<br>        imwrite(imind, cm, gif_filename, 'GIF', 'WriteMode', 'append', 'DelayTime', 0.1);<br>    end<br>end<br><br>close(gcf); % 关闭图形窗口<br>disp(['动画已保存为: ', gif_filename]);</code></pre><br><br><p></p><br>
