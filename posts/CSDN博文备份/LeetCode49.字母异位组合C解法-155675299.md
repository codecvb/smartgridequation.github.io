<p></p><br><br><p>给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。</p><br><br><p><strong>示例 1:</strong></p><br><br><p><strong>输入:</strong> strs = ["eat", "tea", "tan", "ate", "nat", "bat"]</p><br><br><p><strong>输出: </strong>[["bat"],["nat","tan"],["ate","eat","tea"]]</p><br><br><p><strong>解释：</strong></p><br><br><ul><li>在 strs 中没有字符串可以通过重新排列来形成 <code>"bat"</code>。</li><li>字符串 <code>"nat"</code> 和 <code>"tan"</code> 是字母异位词，因为它们可以重新排列以形成彼此。</li><li>字符串 <code>"ate"</code> ，<code>"eat"</code> 和 <code>"tea"</code> 是字母异位词，因为它们可以重新排列以形成彼此。</li></ul><br><br><p><strong>示例 2:</strong></p><br><br><p><strong>输入:</strong> strs = [""]</p><br><br><p><strong>输出: </strong>[[""]]</p><br><br><p><strong>示例 3:</strong></p><br><br><p><strong>输入:</strong> strs = ["a"]</p><br><br><p><strong>输出: </strong>[["a"]]</p><br><br><h4>解题思路</h4><br><br><p>字母异位词的核心特征是：<strong>字符组成完全相同，仅排列顺序不同</strong>。因此可以通过「标准化」每个字符串（如将字符串按字符排序），将字母异位词映射到同一个键，最终把相同键对应的字符串归为一类。</p><br><br><p>具体步骤：</p><br><br><ol><li>遍历字符串数组，对每个字符串进行<strong>排序</strong>（如 "eat" 排序后为 "aet"，"tea" 排序后也为 "aet"），排序后的字符串作为哈希表的键；</li><li>哈希表的值为一个字符串列表，用于存储所有与当前键对应的字母异位词；</li><li>遍历完成后，将哈希表中的所有值提取出来，即为最终结果。</li></ol><br><br><h4>C++ 代码实现</h4><br><br><pre><br><code class="language-cpp">#include <iostream><br>#include <vector><br>#include <string><br>#include <unordered_map><br>#include <algorithm><br>using namespace std;<br><br>class Solution {<br>public:<br>    vector<vector<string>> groupAnagrams(vector<string>& strs) {<br>        // 哈希表：键为排序后的字符串，值为对应的字母异位词列表<br>        unordered_map<string, vector<string>> mp;<br>        <br>        for (string& s : strs) {<br>            // 1. 对当前字符串排序，生成标准化的键<br>            string key = s;<br>            sort(key.begin(), key.end());<br>            // 2. 将原字符串加入对应键的列表中<br>            mp[key].push_back(s);<br>        }<br>        <br>        // 3. 提取哈希表中的所有值，组成结果<br>        vector<vector<string>> res;<br>        for (auto& pair : mp) {<br>            res.push_back(pair.second);<br>        }<br>        <br> ++i) {<br>            cout << "\"" << group[i] << "\"";<br>            if (i != group.size() - 1) cout << ",";<br>        }<br>        cout << "]" << endl;<br>    }<br><br>    // 示例2<br>    vector<string> strs2 = {""};<br>    vector<vector<string>> res2 = solution.groupAnagrams(strs2);<br>    cout << "\n示例2输出：" << endl;<br>    for (auto& group : res2) {<br>        cout << "[";<br>        for (int i = 0; i < group.size(); ++i) {<br>            cout << "\"" << group[i] << "\"";<br>            if (i != group.size() - 1) cout << ",";<br>        }<br>        cout << "]" << endl;<br>    }<br><br>    // 示例3<br>    vector<string> strs3 = {"a"};<br>    vector<vector<string>> res3 = solution.groupAnagrams(strs3);<br>    cout << "\n示例3输出：" << endl;<br>    for (auto& group : res3) {<br>        cout << "[";<br>        for (int i = 0; i < group.size(); ++i) {<br>            cout << "\"" << group[i] << "\"";<br>            if (i != group.size() - 1) cout << ",";<br>        }<br>        cout << "]" << endl;<br>    }<br><br>    return 0;<br>}<br></code></pre><br><br><h4>代码解释</h4><br><br><ol><li><strong>哈希表定义</strong>：<code>unordered_map<string, vector<string>> mp</code> 用于存储「排序后的字符串」与「字母异位词列表」的映射；</li><li><strong>遍历并标准化字符串</strong>：<br>	<ul><li>对每个字符串 <code>s</code>，复制一份到 <code>key</code>，然后对 <code>key</code> 按字符排序（如 "tan" 排序为 "ant"，"nat" 排序也为 "ant"）；</li><li>将原字符串 <code>s</code> 加入 <code>mp[key]</code> 对应的列表中，实现字母异位词的分组；</li></ul><br>	</li><li><strong>提取结果</strong>：遍历哈希表，将每个键对应的列表存入结果数组 <code>res</code>；</li><li><strong>测试用例</strong>：主函数验证了题目给出的三个示例，输出格式与题目要求一致。</li></ol><br><br><h4>进阶优化（针对长字符串）</h4><br><br><p>如果字符串长度较长，排序的时间复杂度（O (k log k)，k 为字符串长度）可能偏高，可优化为「字符计数法」生成键：</p><br><br><ul><li>统计每个字符串中 26 个字母的出现次数，将计数结果拼接为字符串（如 "eat" 计数为 "1,0,0,0,1,0,...,1,0..."），作为哈希表的键；</li><li>该方法的时间复杂度为 O (k) 每字符串，适合长字符串场景。</li></ul><br><br><p>优化后的核心代码片段：</p><br><br><pre><br><code>// 替换原排序逻辑，生成字符计数字符串作为键<br>string getKey(string& s) {<br>    vector<int> count(26, 0);<br>    for (char c : s) {<br>        count[c - 'a']++;<br>    }<br>    string key;<br>    for (int num : count) {<br>        key += to_string(num) + ","; // 加分隔符避免数字拼接歧义（如 11 和 1,1）<br>    }<br>    return key;<br>}<br><br>// 在groupAnagrams中调用：<br>string key = getKey(s);<br>mp[key].push_back(s);<br></code></pre><br><br><h4>复杂度分析</h4><br><br><ul><li><strong>基础版（排序法）</strong>：<br><br>	<ul><li>时间复杂度：O (n * k log k)。n 是字符串数组长度，k 是字符串的最大长度（排序每个字符串需 O (k log k)）；</li><li>空间复杂度：O (n * k)。哈希表需存储所有字符串，最坏情况下占用 O (n*k) 空间。</li></ul><br>	</li><li><strong>优化版（计数法）</strong>：<br>	<ul><li>时间复杂度：O (n * k)。统计字符计数仅需 O (k) 每字符串；</li><li>空间复杂度：O (n * k)。哈希表存储逻辑不变。</li></ul><br>	</li></ul><br><br><p>两种方法均能正确解决问题，可根据字符串长度选择：短字符串用排序法（代码更简洁），长字符串用计数法（效率更高）。</p><br><br><p>解释一下pair.second是什么意思</p><br><br><p>在 C++ 中，<code>pair.second</code> 是访问<strong>键值对容器（如 <code>unordered_map</code>/<code>map</code>）迭代器指向的键值对中「值」部分</strong> 的方式，我们结合之前的字母异位词代码来拆解说明：</p><br><br><h4>1. 先理解 <code>pair</code> 的本质</h4><br><br><p><code>std::pair</code> 是 C++ STL 中的一个模板类，用于存储<strong>一对关联的数据</strong>（可以是不同类型），它有两个公有成员：</p><br><br><ul><li><code>first</code>：表示第一个元素（对应哈希表的「键」）；</li><li><code>second</code>：表示第二个元素（对应哈希表的「值」）。</li></ul><br><br><p>比如哈希表 <code>unordered_map<string, vector<string>> mp</code> 中，每一个键值对的类型是：</p><br><br><p>cpp</p><br><br><p>运行</p><br><br><pre><br><code class="language-cpp">pair<const string, vector<string>>  // first是const string（键），second是vector<string>（值）<br></code></pre><br><br><h4>2. 结合代码看 <code>pair.second</code> 的作用</h4><br><br><p>在字母异位词的代码中，这一段是核心：</p><br><br><pre><br><code class="language-cpp">// 提取哈希表中的所有值，组成结果<br>vector<vector<string>> res;<br>for (auto& pair : mp) {<br>    res.push_back(pair.second);<br>}<br></code></pre><br><br><p>逐行解释：</p><br><br><ul><li><code>for (auto& pair : mp)</code>：遍历哈希表 <code>mp</code> 的每一个键值对，循环变量 <code>pair</code> 就是当前的键值对（类型为 <code>pair<const string, vector<string>></code>）；</li><li><code>pair.first</code>：对应哈希表的「键」（比如排序后的字符串 "aet"）；</li><li><code>pair.second</code>：对应哈希表的「值」（比如存储 ["ate","eat","tea"] 的 <code>vector<string></code>）；</li><li><code>res.push_back(pair.second)</code>：把每个键对应的「字母异位词列表」存入结果数组，最终得到分组后的结果。</li></ul><br><br><h4>3. 举具体例子（结合示例 1）</h4><br><br><p>哈希表 <code>mp</code> 在示例 1 中存储的键值对如下：</p><br><br><table><thead><tr><th>pair.first（键）</th><th>pair.second（值）</th></tr></thead><tbody><tr><td>"abt"</td><td>["bat"]</td></tr><tr><td>"ant"</td><td>["nat","tan"]</td></tr><tr><td>"aet"</td><td>["ate","eat","tea"]</td></tr></tbody></table><br><br><p>遍历 <code>mp</code> 时：</p><br><br><ul><li>第一次循环：<code>pair.first = "abt"</code>，<code>pair.second = ["bat"]</code> → 把 <code>["bat"]</code> 加入结果；</li><li>第二次循环：<code>pair.first = "ant"</code>，<code>pair.second = ["nat","tan"]</code> → 把 <code>["nat","tan"]</code> 加入结果；</li><li>第三次循环：<code>pair.first = "aet"</code>，<code>pair.second = ["ate","eat","tea"]</code> → 把 <code>["ate","eat","tea"]</code> 加入结果。</li></ul><br><br><h4>4. 补充说明</h4><br><br><ul><li>迭代器方式的等价写法：如果不用范围 for 循环，用迭代器遍历的话，逻辑完全一致：<br>	<p>cpp</p><br><br>	<p>运行</p><br><br>	<pre><br><code>for (auto it = mp.begin(); it != mp.end(); ++it) {<br>    res.push_back(it->second);  // it是迭代器，it->second 等价于 (*it).second<br>}<br></code></pre><br>	</li><li><code>auto& pair</code> 中的 <code>&</code>：加引用是为了避免拷贝（尤其是值是大的 <code>vector</code> 时），提升效率；如果不需要修改，也可以用 <code>const auto& pair</code>。</li></ul><br><br><h4>总结</h4><br><br><p><code>pair.second</code> 的核心作用是：<strong>获取键值对中的「值」部分</strong>，在哈希表遍历中，这是提取「键对应的数据」的关键方式。在字母异位词的场景中，我们最终需要的是「分组后的字母异位词列表」（即哈希表的值），因此通过 <code>pair.second</code> 提取这部分数据即可。</p><br>
