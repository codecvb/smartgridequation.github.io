<p> 下面是一个使用 C++ 实现最小二乘法的示例代码，最小二乘法用于拟合线性回归模型 y = ax + b。</p> <br><pre><code class="language-cpp">#include <iostream><br>#include <vector><br><br>// 定义最小二乘法函数<br>std::pair<double, double> leastSquares(const std::vector<double>& x, const std::vector<double>& y) {<br>    int n = x.size();<br>    double sumX = 0.0, sumY = 0.0, sumXY = 0.0, sumX2 = 0.0;<br><br>    // 计算所需的总和<br>    for (int i = 0; i < n; ++i) {<br>        sumX += x[i];<br>        sumY += y[i];<br>        sumXY += x[i] * y[i];<br>        sumX2 += x[i] * x[i];<br>    }<br><br>    // 计算斜率 a 和截距 b<br>    double a = (n * sumXY - sumX * sumY) / (n * sumX2 - sumX * sumX);<br>    double b = (sumY - a * sumX) / n;<br><br>    return std::make_pair(a, b);<br>}<br><br>int main() {<br>    // 示例数据<br>    std::vector<double> x = {1, 2, 3, 4, 5};<br>    std::vector<double> y = {2, 4, 6, 8, 10};<br><br>    // 调用最小二乘法函数<br>    std::pair<double, double> result = leastSquares(x, y);<br>    double a = result.first;<br>    double b = result.second;<br><br>    // 输出结果<br>    std::cout << "拟合直线方程: y = " << a << "x + " << b << std::endl;<br><br>    return 0;<br>}    </code></pre> <br><h4>代码解释</h4> <br><ol><li><strong><code>leastSquares</code> 函数</strong>：该函数接受两个 <code>std::vector<double></code> 类型的参数 <code>x</code> 和 <code>y</code>，分别表示自变量和因变量的数据点。在函数内部，首先计算 x 的总和 <code>sumX</code>、y 的总和 <code>sumY</code>、x 与 y 乘积的总和 <code>sumXY</code> 以及 x 的平方和 <code>sumX2</code>。然后根据最小二乘法的公式计算斜率 a 和截距 b，并将它们作为 <code>std::pair<double, double></code> 类型的结果返回。</li><li><strong><code>main</code> 函数</strong>：定义了示例数据 <code>x</code> 和 <code>y</code>，调用 <code>leastSquares</code> 函数进行最小二乘法拟合，得到斜率 a 和截距 b，并将拟合直线方程输出到控制台。</li></ol> <br><p>你可以将示例数据替换为你自己的数据，以进行不同数据集的拟合。</p> <br><p style="text-align:center"><img alt="" src="https://i-blog.csdnimg.cn/direct/89c8d256383d486d831c4b989b4ebbed.png" /></p> <br><p style="text-align:center"><img alt="" src="https://i-blog.csdnimg.cn/direct/e38425b992744287bf8021a75709b935.png" /> </p> <br><p style="text-align:center"><img alt="" src="https://i-blog.csdnimg.cn/direct/2c2f188bb5b1448a94241c95b6701685.png" /> </p> <br><p style="text-align:center"><img alt="" src="https://i-blog.csdnimg.cn/direct/a79af44b250240dc9833fc8243aadd18.png" /> </p>
