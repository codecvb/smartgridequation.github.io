<h4>实现思路</h4> <br><p>在 Windows 平台下，可以使用 Windows API 编写一个程序来对另一个目标程序进行内存注入。基本步骤如下：</p> <br><ol><li><strong>查找目标进程</strong>：通过进程名找到目标进程的 ID。</li><li><strong>打开目标进程</strong>：使用 <code>OpenProcess</code> 函数打开目标进程，获取进程句柄。</li><li><strong>在目标进程中分配内存</strong>：使用 <code>VirtualAllocEx</code> 函数在目标进程的地址空间中分配一块内存。</li><li><strong>将数据写入目标进程的内存</strong>：使用 <code>WriteProcessMemory</code> 函数将数据写入到目标进程分配的内存中。</li><li><strong>执行注入的代码（可选）</strong>：可以使用 <code>CreateRemoteThread</code> 函数在目标进程中创建一个新的线程来执行注入的代码。</li></ol> <br><h4>示例代码</h4> <br><h5>目标程序（被注入的程序）</h5> <br><pre><code class="language-cpp">#include <iostream><br>#include <windows.h><br><br>int main() {<br>    int value = 10;<br>    std::cout << "Original value: " << value << std::endl;<br>    while (true) {<br>        Sleep(1000);<br>    }<br>    return 0;<br>}</code></pre> <br><h5>注入程序</h5> <br><pre><code class="language-cpp">#include <iostream><br>#undef   UNICODE<br>#include <windows.h><br>#include <tlhelp32.h><br><br>// 通过进程名获取进程 ID<br>DWORD GetProcessId(const char* processName) {<br>	PROCESSENTRY32 processEntry;<br>	processEntry.dwSize = sizeof(PROCESSENTRY32);<br><br>	HANDLE snapshot = CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, NULL);<br>	if (snapshot == INVALID_HANDLE_VALUE) {<br>		return 0;<br>	}<br><br>	if (Process32First(snapshot, &processEntry)) {<br>		do {<br>			if (strcmp(processEntry.szExeFile, processName) == 0) {<br>				CloseHandle(snapshot);<br>				return processEntry.th32ProcessID;<br>			}<br>		} while (Process32Next(snapshot, &processEntry));<br>	}<br><br>	CloseHandle(snapshot);<br>	return 0;<br>}<br><br>int main() {<br>	const char* targetProcessName = "Project1.exe";  // 目标程序的可执行文件名<br>	DWORD targetProcessId = GetProcessId(targetProcessName);<br>	if (targetProcessId == 0) {<br>		std::cout << "Target process not found." << std::endl;<br>		return 1;<br>	}<br><br>	// 打开目标进程<br>	HANDLE targetProcessHandle = OpenProcess(PROCESS_ALL_ACCESS, FALSE, targetProcessId);<br>	if (targetProcessHandle == NULL) {<br>		std::cout << "Failed to open target process." << std::endl;<br>		return 1;<br>	}<br><br>	// 在目标进程中分配内存<br>	int newValue = 20;<br>	SIZE_T bytesToWrite = sizeof(newValue);<br>	LPVOID remoteAddress = VirtualAllocEx(targetProcessHandle, NULL, bytesToWrite, MEM_COMMIT, PAGE_READWRITE);<br>	if (remoteAddress == NULL) {<br>		std::cout << "Failed to allocate memory in target process." << std::endl;<br>		CloseHandle(targetProcessHandle);<br>		return 1;<br>	}<br><br>	// 将数据写入目标进程的内存<br>	BOOL writeResult = WriteProcessMemory(targetProcessHandle, remoteAddress, &newValue, bytesToWrite, NULL);<br>	if (!writeResult) {<br>		std::cout << "Failed to write memory in target process." << std::endl;<br>		VirtualFreeEx(targetProcessHandle, remoteAddress, 0, MEM_RELEASE);<br>		CloseHandle(targetProcessHandle);<br>		return 1;<br>	}<br><br>	std::cout << "Memory injection successful." << std::endl;<br><br>	// 假设我们知道 value 变量在目标进程中的地址，这里只是示例地址，实际需要调试获取<br>	LPVOID targetAddress = remoteAddress; // 替换为实际地址<br><br>	int readValue;<br>	SIZE_T bytesRead;<br>	BOOL readResult = ReadProcessMemory(targetProcessHandle, targetAddress, &readValue, sizeof(readValue), &bytesRead);<br>	if (readResult) {<br>		std::cout << "Value read from target process: " << readValue << std::endl;<br>	}<br>	else {<br>		std::cout << "Failed to read memory from target process." << std::endl;<br>	}<br><br>	// 释放资源<br>	VirtualFreeEx(targetProcessHandle, remoteAddress, 0, MEM_RELEASE);<br>	CloseHandle(targetProcessHandle);<br><br>	return 0;<br>}</code></pre> <br><h4>代码解释</h4> <br><ol><li><strong><code>GetProcessId</code> 函数</strong>：通过进程名查找目标进程的 ID。使用 <code>CreateToolhelp32Snapshot</code> 函数创建一个系统进程快照，然后遍历快照中的所有进程，找到与指定进程名匹配的进程，并返回其 ID。</li><li><strong><code>main</code> 函数</strong>： <br>  <ul><li>调用 <code>GetProcessId</code> 函数获取目标进程的 ID。</li><li>使用 <code>OpenProcess</code> 函数打开目标进程，获取进程句柄。</li><li>使用 <code>VirtualAllocEx</code> 函数在目标进程的地址空间中分配一块内存。</li><li>使用 <code>WriteProcessMemory</code> 函数将新值 <code>20</code> 写入到目标进程分配的内存中。</li><li>最后释放分配的内存并关闭进程句柄。</li></ul> </li></ol> <br><h4>现象和结果</h4> <br><ul><li><strong>现象</strong>：注入程序成功运行后，会在目标进程的地址空间中分配一块内存，并将新值 <code>20</code> 写入该内存。</li><li><strong>结果</strong>：由于目标程序没有主动读取注入的内存，所以在目标程序的控制台窗口中看不到明显的变化。但可以使用调试器（如 Visual Studio 调试器）来查看目标进程的内存，验证注入的内存是否包含新值 <code>20</code>。</li></ul> <br><h4>注意事项</h4> <br><ul><li>这种内存注入方法需要管理员权限才能正常运行，因为需要访问其他进程的内存。</li><li>内存注入应该仅在合法的调试和测试环境中使用，不要用于非法目的。</li><li>效果如下</li><li style="text-align: center;"><img alt="" src="https://i-blog.csdnimg.cn/direct/a44785ac96c14a4f92a1ae96ac941398.png" /></li></ul>
