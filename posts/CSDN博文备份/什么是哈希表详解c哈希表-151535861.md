<h4>什么是哈希表？</h4><br><br><p>哈希表（Hash Table）是一种高效的数据结构，它通过<strong>哈希函数</strong>将键（Key）映射到存储位置（数组索引），实现快速的插入、删除和查找操作（平均时间复杂度为 O (1)）。</p><br><br><p>哈希表的核心思想是：</p><br><br><ol><li>使用数组作为底层存储结构</li><li>通过哈希函数计算键对应的数组索引</li><li>当不同的键映射到相同索引时，使用<strong>哈希冲突解决策略</strong>处理</li></ol><br><br><h4>C++ 中的哈希表实现</h4><br><br><p>C++ 标准库提供了多种哈希表相关容器，主要包括：</p><br><br><ol><li><strong><code>std::unordered_map</code></strong>：键值对映射，键唯一</li><li><strong><code>std::unordered_set</code></strong>：存储唯一键</li><li><strong><code>std::unordered_multimap</code></strong>：允许键重复的键值对映射</li><li><strong><code>std::unordered_multiset</code></strong>：允许键重复的集合</li></ol><br><br><p>这些容器都基于哈希表实现，属于 C++11 及以上标准。</p><br><br><h5>1. <code>std::unordered_map</code> 基本用法</h5><br><br><p></p><br><br><p>C++ unordered_map 示例</p><br><br><p>V1</p><br><br><pre><br><code class="language-cpp">#include <iostream><br>#include <unordered_map><br>#include <string><br><br>int main() {<br>    // 创建一个unordered_map，键为string类型，值为int类型<br>    std::unordered_map<std::string, int> student_scores;<br><br>    // std::endl;<br>    }<br><br>    // 遍历哈希表<br>    std::cout << "\n所有学生分数:" << std::endl;<br>    for (const auto& pair : student_scores) {<br>        std::cout << pair.first << ": " << pair.second << std::endl;<br>    }<br><br>    // 删除元素<br>    student_scores.erase("Bob");<br><br>    // 查看大小<br>    std::cout << "\n当前学生数量: " << student_scores.size() << std::endl;<br><br>    return 0;<br>}<br></code></pre><br><br><h5>2. 哈希冲突解决策略</h5><br><br><p>C++ 哈希表采用<strong>链地址法</strong>（Separate Chaining）解决哈希冲突：</p><br><br><ul><li>底层是一个数组，每个元素是一个链表（或平衡树）的头指针</li><li>当哈希冲突发生时，将新元素添加到对应索引的链表中</li><li>当链表长度超过阈值时，会自动转换为平衡树（如红黑树）以保持高效操作</li></ul><br><br><h5>3. 自定义类型作为键</h5><br><br><p>要将自定义类型用作哈希表的键，需要：</p><br><br><ol><li>提供哈希函数（特化 <code>std::hash</code>）</li><li>提供相等比较运算符（<code>operator==</code>）</li></ol><br><br><p>C++ 自定义哈希表键类型</p><br><br><p>V1</p><br><br><pre><br><code class="language-cpp">#include <iostream><br>#include <unordered_map><br>#include <string><br><br>// 自定义类型<br>struct Person {<br>    std::string 的插入、删除和查找</li><li>适用于需要频繁查找的场景</li></ul><br><br><p><strong>缺点</strong>：</p><br><br><ul><li>元素无序存储</li><li>哈希函数设计不当会导致大量冲突，性能下降</li><li>内存占用通常比树结构更大</li><li>最坏情况下（所有元素哈希冲突）时间复杂度为 O (n)</li></ul><br><br><h4>与 <code>std::map</code> 的对比</h4><br><br><table><thead><tr><th>特性</th><th><code>std::unordered_map</code></th><th><code>std::map</code></th></tr></thead><tbody><tr><td>底层实现</td><td>哈希表</td><td>红黑树</td></tr><tr><td>元素顺序</td><td>无序</td><td>按键排序</td></tr><tr><td>平均查找时间</td><td>O(1)</td><td>O(log n)</td></tr><tr><td>内存占用</td><td>通常更大</td><td>通常更小</td></tr><tr><td>插入性能</td><td>更好（平均）</td><td>较稳定</td></tr></tbody></table><br><br><p>选择建议：</p><br><br><ul><li>需要快速查找且不关心顺序时，选 <code>std::unordered_map</code></li><li>需要有序存储或保证最坏情况性能时，选 <code>std::map</code></li></ul><br><br><p>哈希表是 C++ 中处理快速查找场景的重要工具，合理使用能显著提升程序性能。</p><br><br><p>分享</p><br><br><h4>用哈希表解决几个算法问题，难度为简单或者中等</h4><br><br><p>下面我将使用哈希表解决几个简单到中等难度的算法问题，展示哈希表在实际编程中的应用。</p><br><br><h4>问题 1：两数之和（简单）</h4><br><br><p>给定一个整数数组
