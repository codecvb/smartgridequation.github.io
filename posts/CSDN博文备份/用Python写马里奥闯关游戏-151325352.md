<p>创建一个简化版的超级玛丽游戏。这个游戏实现了马里奥的基本移动、跳跃、收集金币、与敌人互动等核心功能。</p><br><br><pre><br><code class="language-python">import pygame<br>import sys<br>import random<br><br># 初始化pygame<br>pygame.init()<br><br># 游戏窗口设置<br>SCREEN_WIDTH = 800<br>SCREEN_HEIGHT = 450<br>screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))<br>pygame.display.set_caption("超级玛丽")<br><br># 确保中文能正常显示<br>pygame.font.init()<br>font_options = ["SimHei", "WenQuanYi Micro Hei", "Heiti TC", pygame.font.get_default_font()]<br>font = None<br>for font_name in font_options:<br>    try:<br>        font = pygame.font.SysFont(font_name, 36)<br>        break<br>    except:<br>        continue<br><br># 颜色定义<br>SKY_BLUE = (135, 206, 235)<br>WHITE = (255, 255, 255)<br>BLACK = (0, 0, 0)<br>GREEN = (34, 139, 34)    # 地面颜色<br>BROWN = (139, 69, 19)    # 敌人颜色<br>RED = (255, 0, 0)        # 马里奥颜色<br>YELLOW = (255, 215, 0)   # 金币颜色<br>GRAY = (169, 169, 169)   # 砖块颜色<br><br># 游戏帧率<br>clock = pygame.time.Clock()<br>FPS = 60<br><br># 马里奥类<br>class Mario(pygame.sprite.Sprite):<br>    def __init__(self, x, y):<br>        super().__init__()<br>        self.width = 40<br>        self.height = 60<br>        self.image = pygame.Surface((self.width, self.height))<br>        self.image.fill(RED)<br>        self.rect = self.image.get_rect()<br>        self.rect.x = x<br>        self.rect.y = y<br>        <br>        # 移动属性<br>        self.vel_x = 0<br>        self.vel_y = 0<br>        self.speed = 5<br>        self.jump_strength = -15<br>        self.gravity = 0.8<br>        self.on_ground = False<br>    <br>    def update(self, platforms):<br>        # 应用重力<br>        self.vel_y += self.gravity<br>        if self.vel_y > 10:  # 限制最大下落速度<br>            self.vel_y = 10<br>        <br>        # 水平移动<br>        self.rect.x += self.vel_x<br>        <br>        # 水平碰撞检测<br>        for platform in platforms:<br>            if pygame.sprite.collide_rect(self, platform):<br>                if self.vel_x > 0:  # 向右移动<br>                    self.rect.right = platform.rect.left<br>                elif self.vel_x < 0:  # 向左移动<br>                    self.rect.left = platform.rect.right<br>        <br>        # 垂直移动<br>        self.rect.y += self.vel_y<br>        self.on_ground = False<br>        <br>        # 垂直碰撞检测<br>        for platform in platforms:<br>            if pygame.sprite.collide_rect(self, platform):<br>                if self.vel_y > 0:  # 下落<br>                    self.rect.bottom = platform.rect.top<br>                    self.vel_y = 0<br>                    self.on_ground = True<br>                elif self.vel_y < 0:  # 上升<br>                    self.rect.top = platform.rect.bottom<br>                    self.vel_y = 0<br>    <br>    def jump(self):<br>        if self.on_ground:<br>            self.vel_y = self.jump_strength<br>    <br>    def move_left(self):<br>        self.vel_x = -self.speed<br>    <br>    def move_right(self):<br>        self.vel_x = self.speed<br>    <br>    def stop(self):<br>        self.vel_x = 0<br><br># 平台类<br>class Platform(pygame.sprite.Sprite):<br>    def __init__(self, x, y, width, height, color=GREEN):<br>        super().__init__()<br>        self.image = pygame.Surface((width, height))<br>        self.image.fill(color)<br>        self.rect = self.image.get_rect()<br>        self.rect.x = x<br>        self.rect.y = y<br><br># 敌人类<br>class Enemy(pygame.sprite.Sprite):<br>    def __init__(self, x, y, width=40, height=40):<br>        super().__init__()<br>        self.image = pygame.Surface((width, height))<br>        self.image.fill(BROWN)<br>        self.rect = self.image.get_rect()<br>        self.rect.x = x<br>        self.rect.y = y<br>        self.speed = random.choice([-2, 2])<br>    <br>    def update(self, platforms):<br>        self.rect.x += self.speed<br>        <br>        # 碰撞检测，让敌人在平台边缘转向<br>        for platform in platforms:<br>            if pygame.sprite.collide_rect(self, platform):<br>                if self.speed > 0:  # 向右移动<br>                    self.rect.right = platform.rect.left<br>                    self.speed = -self.speed<br>                elif self.speed < 0:  # 向左移动<br>                    self.rect.left = platform.rect.right<br>                    self.speed = -self.speed<br><br># 金币类<br>class Coin(pygame.sprite.Sprite):<br>    def __init__(self, x, y, size=30):<br>        super().__init__()<br>        self.original_image = pygame.Surface((size, size), pygame.SRCALPHA)<br>        self.original_image.fill(YELLOW)<br>        self.image = self.original_image.copy()<br>        self.rect = self.image.get_rect()<br>        self.rect.center = (x, y)<br>        # 添加金币旋转动画<br>        self.angle = 0<br>        self.rotate_speed = 5<br>    <br>    def update(self):<br>        self.angle = (self.angle + self.rotate_speed) % 360<br>        self.image = pygame.transform.rotate(self.original_image, self.angle)<br>        # 保持旋转后位置不变<br>        self.rect = self.image.get_rect(center=self.rect.center)<br><br># 创建游戏关卡<br>def create_level():<br>    platforms = pygame.sprite.Group()<br>    enemies = pygame.sprite.Group()<br>    coins = pygame.sprite.Group()<br>    <br>    # 地面<br>    platforms.add(Platform(0, SCREEN_HEIGHT - 40, SCREEN_WIDTH, 40))<br>    <br>    # 平台和砖块<br>    platforms.add(Platform(200, 350, 150, 20, GRAY))<br>    platforms.add(Platform(400, 300, 150, 20, GRAY))<br>    platforms.add(Platform(600, 250, 150, 20, GRAY))<br>    platforms.add(Platform(300, 200, 150, 20, GRAY))<br>    platforms.add(Platform(100, 150, 150, 20, GRAY))<br>    <br>    # 敌人<br>    enemies.add(Enemy(250, 350 - 40 - 40))  # 放在第一个平台上<br>    enemies.add(Enemy(450, 300 - 40 - 40))  # 放在第二个平台上<br>    <br>    # 金币<br>    coins.add(Coin(275, 350 - 20 - 15))<br>    coins.add(Coin(325, 350 - 20 - 15))<br>    coins.add(Coin(475, 300 - 20 - 15))<br>    coins.add(Coin(525, 300 - 20 - 15))<br>    coins.add(Coin(175, 150 - 20 - 15))<br>    <br>    return platforms, enemies, coins<br><br># 主游戏函数<br>def main():<br>    # 创建游戏元素<br>    platforms, enemies, coins = create_level()<br>    mario = Mario(50, SCREEN_HEIGHT - 40 - 60)  # 初始位置在地面上<br>    <br>    # 创建精灵组 - 分开管理不同类型的精灵<br>    all_sprites = pygame.sprite.Group()<br>    all_sprites.add(mario)<br>    all_sprites.add(platforms)<br>    all_sprites.add(enemies)<br>    all_sprites.add(coins)<br>    <br>    # 游戏变量<br>    score = 0<br>    game_over = False<br>    <br>    # 游戏主循环<br>    running = True<br>    while running:<br>        # 事件处理<br>        for event in pygame.event.get():<br>            if event.type == pygame.QUIT:<br>                running = False<br>            <br>            # 跳跃<br>            if event.type == pygame.KEYDOWN:<br>                if event.key == pygame.K_SPACE and not game_over:<br>                    mario.jump()<br>                if event.key == pygame.K_r and game_over:<br>                    # 重新开始游戏<br>                    platforms, enemies, coins = create_level()<br>                    mario = Mario(50, SCREEN_HEIGHT - 40 - 60)<br>                    all_sprites.empty()<br>                    all_sprites.add(mario)<br>                    all_sprites.add(platforms)<br>                    all_sprites.add(enemies)<br>                    all_sprites.add(coins)<br>                    score = 0<br>                    game_over = False<br>        <br>        if not game_over:<br>            # 持续按键检测<br>            keys = pygame.key.get_pressed()<br>            if keys[pygame.K_LEFT]:<br>                mario.move_left()<br>            elif keys[pygame.K_RIGHT]:<br>                mario.move_right()<br>            else:<br>                mario.stop()<br>            <br>            # 更新游戏状态<br>            mario.update(platforms)<br>            enemies.update(platforms)<br>            coins.update()<br>            <br>            # 检测金币碰撞<br>            coin_hits = pygame.sprite.spritecollide(mario, coins, True)<br>            for coin in coin_hits:<br>                score += 10<br>                # 从所有精灵组中移除金币<br>                if coin in all_sprites:<br>                    all_sprites.remove(coin)<br>            <br>            # 检测敌人碰撞<br>            enemy_hits = pygame.sprite.spritecollide(mario, enemies, False)<br>            if enemy_hits:<br>                # 如果从上方踩敌人<br>                if mario.vel_y > 0 and mario.rect.bottom <= enemy_hits[0].rect.top + 10:<br>                    # 从所有精灵组中移除敌人<br>                    all_sprites.remove(enemy_hits[0])<br>                    enemies.remove(enemy_hits[0])<br>                    mario.vel_y = -10  # 给一个小跳跃<br>                    score += 50<br>                else:<br>                    # 游戏结束<br>                    game_over = True<br>        <br>        # 绘制<br>        screen.fill(SKY_BLUE)  # 天空蓝色背景<br>        all_sprites.draw(screen)<br>        <br>        # 显示分数<br>        score_text = font.render(f"分数: {score}", True, WHITE)<br>        screen.blit(score_text, (10, 10))<br>        <br>        # 游戏结束提示<br>        if game_over:<br>            game_over_text = font.render("游戏结束! 按R键重新开始", True, WHITE)<br>            text_rect = game_over_text.get_rect(center=(SCREEN_WIDTH//2, SCREEN_HEIGHT//2))<br>            screen.blit(game_over_text, text_rect)<br>        <br>        # 刷新屏幕<br>        pygame.display.flip()<br>        <br>        # 控制帧率<br>        clock.tick(FPS)<br>    <br>    pygame.quit()<br>    sys.exit()<br><br>if __name__ == "__main__":<br>    main()<br>    </code></pre><br><br><p>这个超级玛丽游戏实现了以下功能：</p><br><br><ol><li><br>	<p>基本操作：</p><br><br>	<ul><li>左右方向键控制马里奥移动</li><li>空格键控制马里奥跳跃</li><li>游戏结束后按 R 键重新开始</li></ul><br>	</li><li><br>	<p>游戏元素：</p><br><br>	<ul><li>马里奥角色（红色方块）</li><li>地面和平台（灰色方块）</li><li>敌人（棕色方块）</li><li>可收集的金币（黄色旋转方块）</li></ul><br>	</li><li><br>	<p>游戏机制：</p><br><br>	<ul><li>重力效果使马里奥能够下落</li><li>碰撞检测（与平台、敌人、金币）</li><li>计分系统（收集金币和踩敌人得分）</li><li>游戏结束条件（碰到敌人）</li></ul><br>	</li></ol><br><br><p>要运行这个游戏，您需要先安装 Pygame 库，可以使用以下命令安装：</p><br><br><pre><br><code>pip install pygame<br></code></pre><br><br><p></p><br><br><p>您可以进一步扩展这个游戏，比如添加更多关卡、不同类型的敌人、马里奥的状态变化（变大、获得能力）、背景音乐和音效等。</p><br><br><p style="text-align:center"><img alt="" src="https://i-blog.csdnimg.cn/direct/af7bced4caa342aeaaac5e56251be6eb.gif" /></p><br>
