<ul><li> <p><span style="color:#ff9900;">C++的类继承大家还算比较了解。它主要包括</span><span style="color:#fe2c24;">单继承、多继承、虚继承</span><span style="color:#ff9900;">这几方面。</span></p> </li><li> <p><span style="color:#4da8ee;">单继承就是一个子类只继承一个父类，多继承就是一个子类继承多个父类。</span></p> </li><li> <p><span style="color:#956fe7;">其实在C++中，一个子类继承多个父类的情况还是比较常见的。比如，一个子类需要同时继承两个父类的功能，这时候就可以使用多继承。</span></p> </li><li> <p><br /><span style="color:#1c7331;">以下是一个 C++ 中多继承的简单示例代码：</span><br /><br /> cpp<br />  </p> <pre><code class="language-cpp">#include <iostream><br><br>// 父类 Base1<br>class Base1 {<br>public:<br>void method1() {<br>std::cout << "Base1::method1()" << std::endl;<br>}<br>};<br><br>// 父类 Base2<br>class Base2 {<br>public:<br>void method2() {<br>std::cout << "Base2::method2()" << std::endl;<br>}<br>};<br><br>// 子类Derived 同时继承 Base1 和 Base2<br>class Derived : public Base1, public Base2 {<br>public:<br>void derivedMethod() {<br>std::cout << "Derived::derivedMethod()" << std::endl;<br>}<br>};<br><br>int main() {<br>Derived d;<br>d.method1();<br>d.method2();<br>d.derivedMethod();<br><br>return 0;<br>}<br> </code></pre> <p><br /> 在上述代码中， Derived  类同时继承了  Base1  和  Base2  两个父类，可以调用这两个父类中的方法。<br />  </p> <pre><code class="language-css">在多继承的写法上，需要在子类声明时依次列出多个父类，并使用逗号分隔，<br>且每个父类的继承方式（如 public、private 或 protected）也要明确指定。</code></pre> <pre><code class="language-css">需要特别关注的方面主要有几个：<br><br>首先是同名成员的冲突问题。如果多个父类中存在同名的成员（包括数据成员或成员函数），<br>在子类中使用时需要明确指出是从哪个父类继承来的。<br><br>其次是菱形继承可能导致的二义性问题。比如类 D 继承自类 B 和类 C，而 B 和 C 又都<br>继承自类 A，如果 D 中访问 A 中的成员，可能会产生二义性。这时候可能需要使用虚继承来解决。<br><br>还有就是不同父类的构造函数和析构函数的调用顺序，需要按照继承时指定的顺序来进行。</code></pre> <p><br /><span style="color:#fe2c24;">你在实际编写代码的时候，一定要小心处理这些情况，避免出现错误</span></p> </li></ul> <br><p>        <span style="color:#fe2c24;">运行结果如下：</span></p> <br><p style="text-align:center;"><span style="color:#fe2c24;"><img alt="" src="https://i-blog.csdnimg.cn/direct/bf9ae925b603464a8f2ae7fa03b0bfbd.png" /></span></p> <br><p></p> <br><p></p>
