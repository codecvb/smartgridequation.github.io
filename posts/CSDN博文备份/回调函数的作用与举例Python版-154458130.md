<h4>函数回调的作用</h4><br><br><p>函数回调（Callback）是指将一个函数作为参数传递给另一个函数，当特定事件或条件满足时，被传递的函数会被调用。其核心作用包括：</p><br><br><ol><li><strong>解耦逻辑</strong>：将 “事件触发” 与 “事件处理” 分离，使代码更灵活、可复用。</li><li><strong>异步处理</strong>：在异步操作（如网络请求、定时器）完成后，通过回调通知结果。</li><li><strong>事件驱动</strong>：响应特定事件（如用户点击、数据到达）时执行自定义逻辑。</li></ol><br><br><h4>回调函数基础举例</h4><br><br><p>以 “计算器” 为例，将运算逻辑（加、减）作为回调函数传递给主函数：</p><br><br><p>python</p><br><br><pre><br><code class="language-python"># 回调函数：加法<br>def add(a, b):<br>    return a + b<br><br># 回调函数：减法<br>def subtract(a, b):<br>    return a - b<br><br># 主函数：接收回调函数并执行<br>def calculate(a, b, callback):<br>    return callback(a, b)<br><br># 使用回调<br>print(calculate(5, 3, add))      # 输出：8<br>print(calculate(5, 3, subtract)) # 输出：2<br></code></pre><br><br><h4>回调函数处理不同消息机制的写法与实例</h4><br><br><p>消息机制通常指 “事件源产生消息，回调函数处理消息” 的模式，常见场景包括 GUI 事件、网络消息、状态通知等。</p><br><br><h5>1. GUI 事件消息（以 Python Tkinter 为例）</h5><br><br><p><strong>机制</strong>：用户操作（点击按钮、输入文本）产生事件消息，回调函数响应事件。</p><br><br><p>python</p><br><br><pre><br><code class="language-python">import tkinter as tk<br>from tkinter import messagebox<br><br># 回调函数：处理按钮点击消息<br>def on_button_click():<br>    messagebox.showinfo("消息", "按钮被点击了！")<br><br># 回调函数：处理文本输入消息<br>def on_text_change(event):<br>    print(f"输入内容：{event.widget.get()}")<br><br># 创建GUI<br>root = tk.Tk()<br>root.title("消息机制示例")<br><br># 绑定按钮点击消息到回调<br>btn = tk.Button(root, text="点击我", command=on_button_click)<br>btn.pack(pady=10)<br><br># 绑定文本输入消息到回调（带事件参数）<br>entry = tk.Entry(root)<br>entry.pack(pady=10)<br>entry.bind("<KeyRelease>", on_text_change)  # 键盘释放时触发<br><br>root.mainloop()<br></code></pre><br><br><h5>2. 网络消息（以 HTTP 请求回调为例）</h5><br><br><p><strong>机制</strong>：网络请求完成后，通过回调处理响应消息（同步 / 异步均可，异步更常见）。</p><br><br><p>python</p><br><br><pre><br><code class="language-python">import requests<br>from threading import Thread<br><br># 回调函数：处理网络响应消息<br>def handle_response(response):<br>    if response.status_code == 200:<br>        print(f"响应内容：{response.text[:50]}...")<br>    else:<br>        print(f"请求失败，状态码：{response.status_code}")<br><br># 异步发送请求，完成后调用回调<br>def async_request(url, callback):<br>    def _request():<br>        response = requests.get(url)<br>        callback(response)  # 网络消息处理<br>    Thread(target=_request).start()<br><br># 发送请求并指定回调<br>async_request("https://api.github.com", handle_response)<br>print("请求已发送，等待响应...")  # 主线程不阻塞<br></code></pre><br><br><h5>3. 状态机消息（以设备状态变更为例）</h5><br><br><p><strong>机制</strong>：设备状态（如 “启动”“运行”“故障”）变更时，通过回调通知状态消息。</p><br><br><p>python</p><br><br><pre><br><code class="language-python"># 状态回调函数：处理不同状态消息<br>def on_start():<br>    print("设备启动：初始化传感器...")<br><br>def on_running(speed):<br>    print(f"设备运行：当前速度 {speed} rpm")<br><br>def on_error(code):<br>    print(f"设备故障：错误码 {code}，请检修！")<br><br># 设备状态机：根据状态触发对应回调<br>class Device:<br>    def __init__(self):<br>        self.callbacks = {<br>            "start": on_start,<br>            "running": on_running,<br>            "error": on_error<br>        }<br><br>    def set_state(self, state, *args):<br>        if state in self.callbacks:<br>            self.callbacks[state](*args)  # 传递状态参数<br><br># 模拟设备状态变更<br>device = Device()<br>device.set_state("start")         # 触发on_start<br>device.set_state("running", 3000) # 触发on_running(3000)<br>device.set_state("error", 502)    # 触发on_error(502)<br></code></pre><br><br><h5>4. 消息队列（以生产者 - 消费者模型为例）</h5><br><br><p><strong>机制</strong>：生产者发送消息到队列，消费者通过回调函数处理队列中的消息。</p><br><br><p>python</p><br><br><pre><br><code class="language-python">from queue import Queue<br>import time<br>import threading<br><br># 回调函数：处理队列消息<br>def process_message(msg):<br>    print(f"处理消息：{msg}，耗时1秒")<br>    time.sleep(1)  # 模拟处理耗时<br><br># 消费者：循环从队列取消息并调用回调<br>def consumer(queue, callback):<br>    while True:<br>        msg = queue.get()<br>        if msg == "exit":<br>            break<br>        callback(msg)<br>        queue.task_done()<br><br># 生产者：向队列发送消息<br>def producer(queue):<br>    messages = ["消息1", "消息2", "消息3", "exit"]<br>    for msg in messages:<br>        queue.put(msg)<br>        time.sleep(0.5)  # 模拟间隔发送<br><br># 启动队列和线程<br>q = Queue()<br>threading.Thread(target=consumer, args=(q, process_message), daemon=True).start()<br>producer(q)<br>q.join()  # 等待所有消息处理完成<br></code></pre><br><br><h4>总结</h4><br><br><p>回调函数通过 “将处理逻辑作为参数传递”，高效适配了不同消息机制的需求：</p><br><br><ul><li><strong>GUI 事件</strong>：绑定用户操作与响应逻辑；</li><li><strong>网络消息</strong>：异步处理请求结果；</li><li><strong>状态机</strong>：根据状态动态执行不同逻辑；</li><li><strong>消息队列</strong>：解耦生产与消费，灵活处理消息。</li></ul><br><br><p>其核心价值在于 “延迟执行” 和 “逻辑分离”，是事件驱动编程的基础。</p><br>
