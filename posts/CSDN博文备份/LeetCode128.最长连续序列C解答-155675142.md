<p><a href="https://leetcode.cn/problems/longest-consecutive-sequence/" title="128. 最长连续序列" rel="nofollow">128. 最长连续序列</a></p> <br><p>给定一个未排序的整数数组 <code>nums</code> ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。</p> <br><p>请你设计并实现时间复杂度为 <code>O(n)</code><em> </em>的算法解决此问题。</p> <br><p><strong>示例 1：</strong></p> <br><pre><strong>输入：</strong>nums = [100,4,200,1,3,2]<br><strong>输出：</strong>4<br><strong>解释：</strong>最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。</pre> <br><p><strong>示例 2：</strong></p> <br><pre><strong>输入：</strong>nums = [0,3,7,2,5,8,4,6,0,1]<br><strong>输出：</strong>9<br><br><strong>示例 3：</strong></pre> <br><pre><strong>输入：</strong>nums = [1,0,1,2]<br><strong>输出：</strong>3</pre> <br><h4>解题思路</h4> <br><p>要在 O (n) 时间复杂度内解决这个问题，核心思路是利用<strong>哈希集合</strong>快速查找元素，避免重复计算：</p> <br><ol><li>首先将数组所有元素存入哈希集合，实现 O (1) 时间的存在性检查；</li><li>遍历每个元素，仅当当前元素是 “连续序列的起点”（即<code>num-1</code>不在集合中）时，才向后查找连续数字（<code>num+1</code>, <code>num+2</code>...），统计序列长度；</li><li>记录所有连续序列的最大长度，即为答案。</li></ol> <br><p>这种方式确保每个元素最多被访问两次（一次遍历，一次作为连续序列的后续元素），整体时间复杂度为 O (n)。</p> <br><h4>C++ 代码实现</h4> <br><pre><code class="language-cpp">#include <iostream><br>#include <vector><br>#include <unordered_set><br>using namespace std;<br><br>class Solution {<br>public:<br>    int longestConsecutive(vector<int>& nums) {<br>        // 1. 将数组元素存入哈希集合，去重且支持O(1)查找<br>        unordered_set<int> numSet(nums.begin(), nums.end());<br>        int maxLength = 0;<br><br>        // 2. 遍历每个元素，寻找连续序列的起点<br>        for (int num : numSet) {<br>            // 仅当num是起点（num-1不存在）时，才统计连续长度<br>            if (numSet.find(num - 1) == numSet.end()) {<br>                int currentNum = num;<br>                int currentLength = 1;<br><br>                // 向后查找连续数字<br>                while (numSet.find(currentNum + 1) != numSet.end()) {<br>                    currentNum++;<br>                    currentLength++;<br>                }<br><br>                // 更新最大长度<br>                maxLength = max(maxLength, currentLength);<br>            }<br>        }<br><br>        return maxLength;<br>    }<br>};<br><br>// 测试用例<br>int main() {<br>    Solution solution;<br>    <br>    // 示例1<br>    vector<int> nums1 = {100,4,200,1,3,2};<br>    cout << "示例1输出：" << solution.longestConsecutive(nums1) << endl; // 预期4<br><br>    // 示例2<br>    vector<int> nums2 = {0,3,7,2,5,8,4,6,0,1};<br>    cout << "示例2输出：" << solution.longestConsecutive(nums2) << endl; // 预期9<br><br>    // 示例3<br>    vector<int> nums3 = {1,0,1,2};<br>    cout << "示例3输出：" << solution.longestConsecutive(nums3) << endl; // 预期3<br><br>    return 0;<br>}<br></code></pre> <br><h4>代码解释</h4> <br><ol><li><strong>哈希集合初始化</strong>：<code>unordered_set<int> numSet(nums.begin(), nums.end())</code> 将数组元素存入集合，自动去重，且<code>find</code>操作时间复杂度为 O (1)；</li><li><strong>遍历集合找起点</strong>：对每个元素<code>num</code>，检查<code>num-1</code>是否存在，若不存在则说明<code>num</code>是连续序列的起点；</li><li><strong>统计连续长度</strong>：从起点开始，循环查找<code>num+1</code>、<code>num+2</code>...，直到找不到为止，记录当前序列长度；</li><li><strong>更新最大长度</strong>：每次统计完一个序列后，对比并更新全局最大长度；</li><li><strong>测试用例</strong>：主函数中验证了题目给出的三个示例，确保代码正确性。</li></ol> <br><h4>复杂度分析</h4> <br><ul><li><strong>时间复杂度</strong>：O (n)。每个元素最多被访问两次（一次遍历，一次作为连续序列的后续元素），哈希集合的查找操作是 O (1)；</li><li><strong>空间复杂度</strong>：O (n)。哈希集合需要存储所有元素，最坏情况下占用 O (n) 空间。</li></ul>
