陶哲轩博客首页数学问题总结

本文整理自陶哲轩（Terence Tao）个人博客 What’s new 首页的最新数学文章，涵盖 AI 辅助数学证明、形式化验证以及经典多项式猜想的突破。

博客概览

陶哲轩的博客 What’s new 是数学界最具影响力的学术博客之一，副标题为：

Updates on my research and expository papers, discussion of open problems, and other maths-related topics.

博客内容涵盖研究论文更新、开放问题讨论、数学教育以及职业建议等。首页当前（2026年8月）展示了两篇重磅文章，分别涉及 AI 时代的数学证明形式化 和 经典多项式猜想的完整解决。

一、Palomar：Lean 验证数学注册表

发布日期： 2026年8月18日

1.1 背景

近年来，AI 生成的数学证明如雨后春笋般涌现，其中不少已在证明助手语言 Lean 中完成形式化。然而，验证一个 Lean 代码库是否真正证明了其所声称的结论并非易事，尤其对于不熟悉 Lean 的读者而言。需要检查：

  • 所声称的形式化 Lean 语句是否有通过类型检查（typecheck）的证明；
  • 证明中是否包含"作弊"手段，例如额外添加公理；
  • 形式化语句在语义上是否与非形式化描述的结论相符。

1.2 Palomar 是什么

为了解决这一问题，陶哲轩宣布 Palomar（以帕洛玛天文台命名）正式开放提交。这是一个由 Lean FRO 和 ICARM 发起的注册表项目，陶哲轩担任科学顾问委员会成员。

Palomar 可以理解为 Lean 证明的预印本服务器。更准确地说，它是一个外部 GitHub 仓库（或更精确地，由特定 Git commit 表示的仓库"快照"）的注册表，这些仓库包含遵循当前最佳实践的 Lean 代码。

1.3 提交要求

每个提交的仓库需包含三个核心文件：

文件 作用
challenge file 用 Lean 编写的简短、人类可读的结果描述
solution module 对 challenge file 中结果的（任意长度的）证明
formalization.yaml 用非形式化语言描述结果，并包含元数据和声明

1.4 验证机制

提交后，Palomar 执行两项检查：

  • 检查 (a)： 纯机械检查，使用 Lean 工具 Comparator 验证 solution module 通过类型检查并精确证明 challenge file 中的结果；
  • 检查 (b)： 非确定性检查，由大语言模型验证 formalization.yaml 中的非形式化描述与 challenge file 中的结果相符。

通过两项检查的仓库即可在 Palomar 注册。需要强调的是，Palomar 不是 同行评审期刊，其检查远不及真正的人工同行评审严格。

1.5 意义

陶哲轩本人已成功将 Sendov 猜想的形式化证明提交至 Palomar 作为测试。这一项目标志着数学研究在 AI 时代的新范式：人机协作的证明生成 + 机器可验证的形式化注册表。

二、Sendov 猜想的证明消化

发布日期： 2026年8月12日

这是本次总结的重点，涉及一个有着 60 余年历史的经典数学猜想的完整解决。

2.1 猜想陈述

猜想 1（Sendov 猜想）

设 n≥2n \geq 2n≥2，p:C→Cp: \mathbb{C} \to \mathbb{C}p:C→C 是一个所有零点都在单位圆盘内的 nnn 次多项式。则对于 ppp 的每一个零点 aaa，存在 ppp 的一个临界点 ζ\zetaζ，使得

∣ζ−a∣≤1.|\zeta - a| \leq 1.∣ζ−a∣≤1.

猜想 2（Phelps–Rodriguez 猜想，加强版）

设 n≥2n \geq 2n≥2，p:C→Cp: \mathbb{C} \to \mathbb{C}p:C→C 是一个所有零点都在单位圆盘内的 nnn 次多项式。则对于 ppp 的每一个零点 aaa，存在 ppp 的一个临界点 ζ\zetaζ，使得

∣ζ−a∣<1,|\zeta - a| < 1,∣ζ−a∣<1,

除非 aaa 在单位圆上且 ppp 是 zn−anz^n - a^nzn−an 的标量倍数。

猜想 3（内部 Sendov 猜想）

设 n≥2n \geq 2n≥2，p:C→Cp: \mathbb{C} \to \mathbb{C}p:C→C 是一个所有零点都在单位圆盘内的 nnn 次多项式。若 0≤a<10 \leq a < 10≤a<1 是 ppp 的零点，则存在 ppp 的一个临界点 ζ\zetaζ，使得

∣ζ−a∣<1.|\zeta - a| < 1.∣ζ−a∣<1.

通过绕原点旋转，可将 aaa 规范化为满足 0≤a≤10 \leq a \leq 10≤a≤1 的实数。Rubinstein 的工作已确立 a=1a = 1a=1 的情形，因此只需考虑 0≤a<10 \leq a < 10≤a<1。猜想 1 和猜想 2 均可由猜想 3 推出。

2.2 历史进展

阶段 结果
低次情形 n≤8n \leq 8n≤8 已被证明（Brown 和 Xiang 等）
高次情形 充分大的 nnn 已被陶哲轩本人证明
中间情形 长期悬而未决
2026年 Lech Mazur 使用 AI 工具对所有 n≥2n \geq 2n≥2 完成证明，并在 Lean 中验证

陶哲轩的工作是将 AI 生成的证明进行"人类消化"（human digestion），整理成可发表的预印本形式，并将证明置于先前文献的适当语境中，简化和优化论证以突出核心思想。

2.3 证明方法概述

证明采用 反证法。假设存在一个反例，即存在一个 n≥5n \geq 5n≥5 次多项式 ppp，其零点为

a,z1,…,zn−1,a, z_1, \ldots, z_{n-1},a,z1​,…,zn−1​,

其中 0≤a<10 \leq a < 10≤a<1，zjz_jzj​（j=1,…,n−1j = 1, \ldots, n-1j=1,…,n−1）在闭单位圆盘内，且所有临界点到 aaa 的距离都至少为 1。

为捕捉临界点距 aaa 至少为 1 的事实，将临界点写为

a−1q1,…,a−1qn−1,a - \frac{1}{q_1}, \ldots, a - \frac{1}{q_{n-1}},a−q1​1​,…,a−qn−1​1​,

其中 q1,…,qn−1q_1, \ldots, q_{n-1}q1​,…,qn−1​ 为闭单位圆盘内的非零复数。

核心工具：Maclaurin 不等式

证明中最深刻的不等式工具是 Maclaurin 不等式。实际上只需要其一个特殊情形，可由算术平均-调和平均不等式和归纳论证导出。

证明的初等性

值得注意的是，整个证明非常初等：

  • 除了代数基本定理和 Möbius 变换的基本事实外，不使用复分析；
  • 最深刻的输入仅是 Maclaurin 不等式的一个特殊情形。

2.4 形式化验证

陶哲轩使用 AI 代理将整个论证在 Lean 中形式化，并通过小幅修改扩展到所有 n≥2n \geq 2n≥2。形式化代码约 15,000 行，而原始 AI 生成的证明约有 90,000 行——消化后的证明更加精简优雅。

2.5 示例

例 4： 若 p(z)=zn−1p(z) = z^n - 1p(z)=zn−1 且 a=1a = 1a=1，则 z1,…,zn−1z_1, \ldots, z_{n-1}z1​,…,zn−1​ 是非平凡的 nnn 次单位根，而 q1,…,qn−1q_1, \ldots, q_{n-1}q1​,…,qn−1​ 全部等于 1。严格来说，这并不是猜想 3 的反例（因为 a=1a = 1a=1 不在内部）。

三、总结与启示

3.1 两篇文章的关联

这两篇文章并非孤立：Sendov 猜想的形式化证明正是第一个提交到 Palomar 注册表的测试案例。二者共同展示了数学研究的新范式：

AI 辅助证明生成 → 人类消化整理 → Lean 形式化验证 → Palomar 注册发布

3.2 关键数据

指标 数值
Sendov 猜想历史 60+ 年
证明覆盖范围 所有 n≥2n \geq 2n≥2
Lean 形式化代码（消化后） ~15,000 行
原始 AI 证明代码 ~90,000 行
证明核心工具 Maclaurin 不等式

3.3 对数学研究的启示

  1. AI 不是替代，而是协作：AI 生成的证明需要数学家进行"消化"、简化和语境化；
  2. 形式化验证成为标准：Lean 等证明助手让数学证明可以被机器精确检验；
  3. 经典问题仍有突破空间：Sendov 猜想这样的"老问题"在新方法下可以被完全解决；
  4. 初等方法的力量：一个看似深刻的猜想，其证明核心可以是非常初等的不等式。
