在 Python 中，你可以使用内置的 pow() 函数来高效地计算幂运算和取模运算。以下是计算 2 的 100 次方对 5 取模的代码：

result = pow(2, 100, 5)
print(result)

上述代码中，pow() 函数的第一个参数是底数，第二个参数是指数，第三个参数是模数。它会直接计算出幂运算结果对模数取模的值。运行代码后，会打印出最终结果。

在数字没有超出int大小范围时，可以用以下代码计算

#include <stdio.h>

// 函数用于计算 base 的 exponent 次方对 modulus 取模的结果
int powerMod(int base, int exponent, int modulus) {
    int result = 1;
    base = base % modulus;
    while (exponent > 0) {
        if (exponent % 2 == 1) {
            result = (result * base) % modulus;
        }
        exponent = exponent >> 1;
        base = (base * base) % modulus;
    }
    return result;
}

int main() {
    int base = 2;
    int exponent = 100;
    int modulus = 5;
    int result = powerMod(base, exponent, modulus);
    printf("%d\n", result);
    return 0;
}

在考虑变量大小的情况下，我们有如下代码

#include <stdio.h>

// 函数用于计算 base 的 exponent 次方对 modulus 取模的结果
int powerMod(int base, int exponent, int modulus) {
    int result = 1;
    // 在每次乘法操作后进行取模，防止溢出
    while (exponent > 0) {
        if (exponent % 2 == 1) {
            result = (result * base) % modulus;
        }
        exponent = exponent / 2;
        base = (base * base) % modulus;
    }
    return result;
}

int main() {
    int base = 2;
    int exponent = 100;
    int modulus = 5;
    int result = powerMod(base, exponent, modulus);
    printf("%d\n", result);
    return 0;
}

在 powerMod 函数里，每一次进行乘法运算后都进行取模操作，这样中间结果就不会超出 int 类型的表示范围。同时，运用快速幂算法能有效减少乘法运算的次数，提高计算效率。

exponent 相关计算，其实是在快速幂算法里的操作，目的是高效地算出一个数的幂次。下面详细解释下 exponent 在代码里是如何被计算的，以及这么做的原因。

快速幂算法原理

快速幂算法的核心思路是把指数 exponent 用二进制形式来表示，进而把幂运算转化成一系列的平方和乘法操作。这可以显著减少乘法运算的次数，让时间复杂度从常规幂运算的 (O(n)) 降低到 (O(log n))。

代码中 exponent 的计算步骤

下面是代码片段：

while (exponent > 0) {
    if (exponent % 2 == 1) {
        result = (result * base) % modulus;
    }
    exponent = exponent / 2;
    base = (base * base) % modulus;
}
1. 判断 exponent 是否为奇数

c

if (exponent % 2 == 1) {
    result = (result * base) % modulus;
}
  • exponent % 2 == 1 用于判断 exponent 是否为奇数。在二进制表示中，奇数的最低位是 1，偶数的最低位是 0。
  • 若 exponent 为奇数，就意味着当前二进制位是 1，需要把当前的 base 乘到结果 result 里，并且取模以避免溢出。
2. 指数右移（除以 2）

c

exponent = exponent / 2;
  • 这行代码把 exponent 除以 2，等同于将 exponent 的二进制表示向右移一位。这样做是为了处理下一个二进制位。
3. 底数平方

c

base = (base * base) % modulus;
  • 每次循环时，base 都会平方。这是因为随着指数右移，每一位对应的幂次都是前一位的平方。例如，(2^2 = 4)，(2^4 = 16)，(2^8 = 256) 等。
  • 同样要进行取模操作，防止溢出。

示例

假设要计算 (2^{10})，10 的二进制表示是 1010。

  • 初始时，base = 2，exponent = 10，result = 1。
  • 第一次循环：
    • exponent = 10 是偶数，不更新 result。
    • exponent 除以 2 后变为 5。
    • base 平方变为 (2^2 = 4)。
  • 第二次循环：
    • exponent = 5 是奇数，result = result * base = 1 * 4 = 4。
    • exponent 除以 2 后变为 2。
    • base 平方变为 (4^2 = 16)。
  • 第三次循环：
    • exponent = 2 是偶数，不更新 result。
    • exponent 除以 2 后变为 1。
    • base 平方变为 (16^2 = 256)。
  • 第四次循环：
    • exponent = 1 是奇数，result = result * base = 4 * 256 = 1024。
    • exponent 除以 2 后变为 0，循环结束。

最终结果就是 (2^{10} = 1024)。

通过这种方式，快速幂算法能够高效地计算幂次，尤其是在指数很大的情况下。
