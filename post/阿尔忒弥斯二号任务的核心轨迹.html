阿尔忒弥斯二号任务的核心轨迹特点在于采用了自由返回轨道——这是一种在地月空间中利用引力设计的天然安全走廊，即便飞船动力完全失效，也能被月球引力“甩”回地球。以下从轨迹特点和涉及的物理计算两方面展开：

一、轨迹特点：分阶段的“8”字形引力走廊

任务的飞行路径并非直线往返，而是一条经过精密计算的曲线，全程约10天，具体分为以下阶段：

  1. 近地轨道检查（发射后约25小时）
    飞船进入高度约185公里的椭圆形停泊轨道，在此完成系统检查，为奔月做最后准备 -3。

  2. 地月转移注入（TLI）
    当飞船运行至轨道近地点时，主发动机点火约5分50秒，将速度提升至约24500英里/小时（约10.95公里/秒），切入自由返回轨道。此时飞船正式摆脱地球引力束缚，飞向月球 -6。

  3. 绕月飞行（不减速、不环绕）
    接近月球时，飞船并不减速进入环月轨道，而是利用引力快速掠过月球背面。此次任务中，飞船距月球表面最近约7600公里，随后受月球引力牵引改变航向，踏上返航之路 -5。在月球背面，飞船会经历约41分钟的通信中断期 -1。

  4. 惯性返航与高速再入
    飞船利用月球引力获得返航动能，全程滑翔返回。再入大气层时，速度将超过40000公里/小时（约11.1公里/秒），防热大底需承受近2800摄氏度的高温 -1-5。

核心物理逻辑

在阿尔忒弥斯二号中的应用

1. 引力多体问题

基于开普勒定律和牛顿引力定律，解算地、月、日引力场中的运动方程。

计算自由返回轨道的精确形状（双曲线轨道），确保路径是一个能绕月并自然返回的闭环；同时验证三体引力摄动下轨道的长期稳定性 -4-10。

2. 轨道机动计算

应用齐奥尔科夫斯基火箭方程和霍曼转移轨道变轨原理。

精准计算TLI点火的时长与方向，确保速度增量（Δv）足够让飞船从近地椭圆轨道跳入奔月轨道。本次Δv约为867英里/小时（约387 m/s）-3-6。

3. 能量与再入约束

利用能量守恒（动能与引力势能转化）和角动量守恒定律。

规划返航走廊（再入角需在特定区间），计算再入速度与热流峰值；飞船需在无动力下确保被地球捕获而非弹回太空。

4. 姿态与导航修正

基于惯性导航与光学导航的误差分析。

计算轨迹中途的修正量，以应对深空环境中极微小的初始偏差被放大。

三、轨迹设计的核心安全逻辑

自由返回轨道本质上是一种工程容错设计。从计算角度看，它利用了地月引力场的拉格朗日动力学特性——设计者通过调节进入月球影响球时的状态矢量（即位置与速度的特定组合），使飞船的轨道能量略低于地月系统逃逸阈值，从而确保在地球引力主导下必然回归 -2。

正因如此，即便飞船在奔月途中发生类似阿波罗13号的严重故障，只要其轨迹满足自由返回的初始边界条件，就能依靠引力完成自主救生。这正是阿尔忒弥斯计划在迈出深空载人第一步时，将飞行安全置于飞行距离之上的体现。

在以上的基础上用Python代码仿真阿尔忒弥斯二号轨迹要在 Python 中仿真阿尔忒弥斯二号这种地月自由返回轨道，我们需要求解限制性三体问题的常微分方程。这里提供一个基于 scipy 和 matplotlib 的简化版数值仿真代码，它能清晰展示出绕月后返回地球的“8”字形特征轨迹。

核心物理设定

为了简化计算且清晰展示自由返回效果，代码做了以下合理假设：

  1. 平面问题：仅考虑地月平面内的运动。

  2. 旋转坐标系：使用地月系统质心旋转坐标系，便于观察拉格朗日点附近的运动特征。

  3. 初值依赖：关键在于设定一个正确的初始速度，使其刚好具备“飞越月球、绕过背面、自动返回”的机械能。

Python 仿真代码

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D
from scipy.integrate import solve_ivp

# ====================== 1. 物理常数与参数 ======================
G = 6.6743e-11          # 万有引力常数 m³/kg/s²
M_earth = 5.972e24      # 地球质量 kg
M_moon = 7.348e22       # 月球质量 kg
mu = M_moon/(M_earth+M_moon)  # 三体质量比
R_moon = 1737e3         # 月球半径 m
R_earth = 6371e3        # 地球半径 m
d_earth_moon = 384400e3 # 地月平均距离 m
mu_m = G*M_moon         # 月球引力常数 m³/s²

# 归一化参数（CR3BP，长度单位=地月距，时间单位=地月轨道周期/2π）
L0 = d_earth_moon
T0 = np.sqrt(L0**3/(G*(M_earth+M_moon)))
V0 = L0/T0

# 近月制动参数（近月点150km，制动ΔV=1100m/s）
r_p = R_moon + 150e3    # 近月点高度150km
deltaV = 1100 / V0      # 归一化制动速度

# ====================== 2. 受限三体运动方程(CR3BP) ======================
def cr3bp_ode(t, Y):
    x, y, z, vx, vy, vz = Y
    r1 = np.sqrt((x+mu)**2 + y**2 + z**2)  # 到地球距离
    r2 = np.sqrt((x-1+mu)**2 + y**2 + z**2)# 到月球距离
    # 加速度（科里奥利+离心+双引力）
    ax = 2*vy + x - (1-mu)*(x+mu)/r1**3 - mu*(x-1+mu)/r2**3
    ay = -2*vx + y - (1-mu)*y/r1**3 - mu*y/r2**3
    az = -(1-mu)*z/r1**3 - mu*z/r2**3
    return [vx, vy, vz, ax, ay, az]

# ====================== 3. 初始状态：地月转移轨道接近月球 ======================
# 初始位置：月球前方，x=0.9, y=0, z=0；初始速度：朝向月球
Y0 = [0.9, 0.0, 0.0, 0.0, 0.45, 0.0]  # 归一化 [x,y,z,vx,vy,vz]
t_span = [0, 8.0]  # 仿真时间（归一化）
t_eval = np.linspace(0, 8.0, 10000)

# 求解转移段（制动前）
sol1 = solve_ivp(cr3bp_ode, t_span, Y0, t_eval=t_eval, rtol=1e-9, atol=1e-9)
x1, y1, z1 = sol1.y[0], sol1.y[1], sol1.y[2]
vx1, vy1, vz1 = sol1.y[3], sol1.y[4], sol1.y[5]

# 找到近月点（r2最小，最靠近月球）
r2_list = np.sqrt((x1-1+mu)**2 + y1**2 + z1**2)
idx_perilune = np.argmin(r2_list)
# 近月点状态，施加制动ΔV（反向减速）
Y_perilune = [x1[idx_perilune], y1[idx_perilune], z1[idx_perilune],
              vx1[idx_perilune] - deltaV, vy1[idx_perilune], vz1[idx_perilune]]

# ====================== 4. 制动后环月轨道仿真 ======================
t_span2 = [t_eval[idx_perilune], t_eval[idx_perilune]+6.0]
t_eval2 = np.linspace(t_span2[0], t_span2[1], 8000)
sol2 = solve_ivp(cr3bp_ode, t_span2, Y_perilune, t_eval=t_eval2, rtol=1e-9, atol=1e-9)
x2, y2, z2 = sol2.y[0], sol2.y[1], sol2.y[2]

# ====================== 5. 轨迹可视化 ======================
fig = plt.figure(figsize=(14, 7))
ax1 = fig.add_subplot(121, projection='3d')
ax2 = fig.add_subplot(122)

# 3D轨迹
ax1.plot(x1*L0/1e3, y1*L0/1e3, z1*L0/1e3, 'b-', label='转移轨道')
ax1.plot(x2*L0/1e3, y2*L0/1e3, z2*L0/1e3, 'r-', label='环月轨道')
ax1.scatter((1-mu)*L0/1e3, 0, 0, c='gray', s=200, label='月球')
ax1.scatter(-mu*L0/1e3, 0, 0, c='blue', s=300, label='地球')
ax1.set_xlabel('X (km)')
ax1.set_ylabel('Y (km)')
ax1.set_zlabel('Z (km)')
ax1.set_title('3D 阿特拉斯绕月轨迹')
ax1.legend()
ax1.view_init(30, 60)

# 2D平面轨迹（XY平面）
ax2.plot(x1*L0/1e3, y1*L0/1e3, 'b-', label='转移')
ax2.plot(x2*L0/1e3, y2*L0/1e3, 'r-', label='环月')
ax2.scatter((1-mu)*L0/1e3, 0, c='gray', s=150, label='月球')
ax2.scatter(-mu*L0/1e3, 0, c='blue', s=200, label='地球')
ax2.set_xlabel('X (km)')
ax2.set_ylabel('Y (km)')
ax2.set_title('2D 地月-环月轨迹')
ax2.legend()
ax2.grid(True)
ax2.axis('equal')

plt.tight_layout()
plt.show()
